Delivered behavior
An optional Prolog library composes into the existing world ontology and owns
the generic hinged close/cancel capability. The same production constructor,
action, selector, native joint, authenticated observation and finish path serves
both a vertical door and a horizontal compound lid. The examples differ only in
ontology data/rules: axis, placement, shape, baseline, target, motor and their
completion consequence. Rest checkpoints use the same observation envelope.

Native mechanics receive explicit references/revisions, local axis/anchors,
limits and physical commands. Runtime admission checks the common anchored
frame and lifetime. Neither layer interprets closing/closed/blocked or an
object-specific payload. The superseded door API, Boolean motor interface,
geometry-inferred pivot and payload-specific runtime clauses were removed.
There are no aliases or old/new compatibility branches.

Governance and lifecycle
Existing action, multiwrite, owned-event, actor custody, exact original outcome,
resource subscription and verified-projection owners remain authoritative.
Completion result/checkpoint/event and authored receiver consequences commit
in one existing transaction. Uncertainty cannot authorize resubmission.
Shared-support moves revise all members and cancel active work atomically.
Completed results remain historical, and movement removes their checkpoints.
Recovery installs current verified state without replaying completed reactions.
The unchanged client path remains the sole writer of physics body poses.

Limits and deployment
This profile supports fixed-to-dynamic revolute joints with one shared local
axis, explicit anchors and angular spans up to 3141mrad. An out-of-range sample
or checkpoint is refused, including numerical overshoot at a travel limit;
target tolerances should be authored inside that interval. It does not invent
a result or clamp authenticated evidence. Cancellation remains explicit.
Changing an active close's control definition to hold is invalid; the governed
cancel action stops it. General joint catalogues and terrain streaming are
outside this repair.

This is a coordinated format replacement. The deployment contract in plan.txt
requires compatible validators/consumers and governed source installation or
an explicitly recorded clean refound; package files cannot rewrite retained
founding rules or signed custody. No network, server, ledger or browser mutation
occurred during this repair. QUD.36 live normal-view acceptance and QUD.26 XR
acceptance remain separate. QUD.27 was completed before this scope.
