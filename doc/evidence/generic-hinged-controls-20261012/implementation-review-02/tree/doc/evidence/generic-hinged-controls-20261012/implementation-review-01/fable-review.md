The finish never removes the custody row (confirmed by the obstructed-door test reading it after finish), so after the move the hinge is `idle` with committed custody. Result: `hinged_custody_held` forever. The rest path does not have this bug because `physics_cancel_rest_edit` leaves `finished(Sample)` intact (`quod_physics.pl:781-784`), so `physics_rest_replaceable` still succeeds. Minimum fix: keep the state for non-closing members (`State = closing(R) -> After = cancelled(R) ; After = State`).
