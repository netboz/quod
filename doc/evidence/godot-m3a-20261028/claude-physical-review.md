## Blockers: invariants the candidate needs and the source does not have

**1. Destination = simulation world is baked into six sites, not one.** The equation `World = world_ref(Ns,Anchor,Space), space_assignment(Entity, Assignment, entity_ref(Ns,Anchor,Space))` appears in `physics_definition_projection` ([quod_physics.pl:81](/home/yan/src/quod_worktrees/pearl-stone/priv/ontologies/quod_physics.pl:81)), `physics_delegate_definition` (:95), `physics_redelegate_definition` (:198), `physics_definition_consequence` (:220), and `physics_refresh_definition` reads `space_placement(W,Subject,Assignment)` at the world (:228). The runtime goal repeats it at [quod_runtime.erl:2882](/home/yan/src/quod_worktrees/pearl-stone/src/quod_runtime.erl:2882). Generalize once: the source export binds the delegate to the entity's exact assignment revision for any destination, and the root verifies the destination through its own domain membership. Leave `physics_definition_projection` as the only source export.

**2. The physical hook never fires at an ordinary child.** `space_change_physics` ([quod_space.pl:266](/home/yan/src/quod_worktrees/pearl-stone/priv/ontologies/quod_space.pl:266)) calls the hook only when the space is a `physical_space` or already holds a live body for that subject at that space. With S1/S2 ordinary, placing E into S2 or withdrawing S2 from S1 never reaches S0's world, so bodies are never created and stale bodies survive a chain break. Add a third condition, "this space holds a domain assignment", and route the composed hook to the root owner in the same transaction. This is the concrete missing capability; it is not a second engine.

**3. Placing a space into an enabled physical root refuses today.** `physics_space_change(W,Subject,admitted)` ([quod_physics.pl:108](/home/yan/src/quod_worktrees/pearl-stone/priv/ontologies/quod_physics.pl:108)) demands exactly one `physics_admission/4` row and allocates a body. S1 is a frame, not a collider. A frame-admission clause must assert domain membership at the root plus a child-side domain assignment, and allocate no body. The `withdrawn` clause (:124) expects exactly one body; for a frame it must remove every body under that path through `physics_removable_body` (:264), so a hinged, controlled or custodied nested body refuses visibly. Keep that refusal.

**4. The live binding fences only the entity's own assignment.** `live(Subject, Assignment, Revision, Digest)` (:123) is untouched when S2 leaves S1, S1's transform changes, S1 drops its contents exterior, or exposure is revoked. The root row must carry the exact path as `edge(SpaceRef, PlacementRevision)` entries plus a digest of the composed edge transforms, and every edge transition must rewrite or remove it atomically (blocker 2 supplies the hook). Runtime side, `source_world_affected` (:1986) only tracks reads at the entity's source identity. Edge owners that differ from E's owner are invisible unless `resolve_physics_body` (:2870) also opens `{physics_source, World, EdgeIdentity}` readers. That reuses the retained-reader and pause-on-verify path and keeps "no mutable copy". In the S0/S1/S2-in-U fixture every edge is local and `select_resource` captures the dependency for free, so the fixture must include one foreign-storage edge or state that the foreign reader path is unexercised.

**5. A composed baseline cannot be an integer Euler pose.** `physics_world_pose` (:641) accepts integer mm and integer milliradians; `canonical_pose` ([quod_physics.erl:1092](/home/yan/src/quod_worktrees/pearl-stone/src/quod_physics.erl:1092)) emits `{world_mm, IntegerPosition, EulerRadians}` and `quod_physics_coordinates:plan/7` requires integer points. Composing T(S0←S1)·T(S1←S2)·local gives a non-integer position and a rotation that is not an XYZ triple. Introduce one pose descriptor `framed(Chain, LocalPose)` with the chain parent-first in authored integers, and compose it in `canonical_pose` to a float position plus quaternion. Round only for the window origin. Note the unit split: space transforms are degrees (`space_transform`, quod_space.pl:57) while physics rotations are milliradians (:642). Convert in that one Erlang function, not in Prolog and not on the client.

Resolve through the child's domain assignment to the root world, and extend `simulation_view/7` (:518) with the view's frame chain so poses in root coordinates can be expressed in S1's frame. `body_bindings` ([quod_client_view.erl:551](/home/yan/src/quod_worktrees/pearl-stone/src/quod_client_view.erl:551)) will reject the view until this is done.

## Advice

- **Reuse the delegate shape for spaces.** A child-side `space_domain_delegate(Space, World, Authority, Assignment)` bound to the space's own placement revision mirrors `physics_definition_delegate`. `physics_assign_authority` (:177) then must redelegate both kinds, or replacing an authority strands child delegates.
- **Admission rows must become rules.** The root cannot author `physics_admission/4` for arbitrary nested entities; derive the pose from the source's committed transform through `::` and the kind from root policy over the subject's class.
- **Display copies need an explicit purpose.** `world_view` unions and dedups `space_contains` (live :444), and `entity_scene/3` at S1's owner cannot tell a placement path from a `space_member` display. Pass `exposure(Path, physical|display)` into the contents expansion and emit `body_pose` only on the physical path. The display path also carries the D5 cycle stack.
- **`relative(Parent, body_pose)` is absolute per [physics-native.md:781](/home/yan/src/quod_worktrees/pearl-stone/doc/physics-native.md:781).** So nested group transforms only move decorative children, and body-driven marks already sit in root coordinates. Confirm the Godot client keeps that semantic before relying on it.
- **In-flight `space_travel` ordering** (live quod_space.pl:249): the transform attribute is replaced after `space_place`, so a domain destination would compose the old pose. Update the pose before placement or pass it to the hook. Also `findall(T, attribute(Entity,transform,T), [PreviousPose])` fails for an entity that never had one.
- **Pause granularity** is per world ([quod_runtime.erl:1949](/home/yan/src/quod_worktrees/pearl-stone/src/quod_runtime.erl:1949)); any edge or source verifying a delta pauses the whole root world. Acceptable for M3a, but do not claim per-component pause.
- **Subscriptions.** `physics_subscription/2` (:145) needs an authored `subscribes/2` at the root for every source and edge owner.
