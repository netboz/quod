Qualification uses fresh signed software fixtures and the shared native Controls.
Unchanged server/core, Stage2 source-recovery and package gates are referenced,
not repeated as new coverage. Each new failed label remains intact.

The supported graphical operations are finite. Class names/parents are existing
source symbols, attribute values entered here are text, and memberships can only
be removed as exact authored facts. Instance creation must use the class's
existing offered action and generated identity. Removing a fact does not cascade,
retire an ontology or delete an entity's history. Policy and arbitrary rule bodies
remain in their existing text/source representations; this is no universal graph
editor or new permissions/founding mechanism.
