proposal was dropped: the existing Erlang conversion stays byte-for-byte intact.

from the larger actual overflow point; the review's suggested boundary+1 overflow
claim is not assumed.

bridge base. The existing personal world received its source via ordinary signed

module manifest records external module names and BEAM digests, not this package
file; no manifest or committed Prolog source is rewritten by replacing the NIF.

worst-case normal-error bound. Every collider is still cast, final occupancy is

remain unchanged. Large-offset tests and bounded traces check its practical margin.

oracle threshold failed on vertices outside the authored skin. That threshold was

regression. The final oracle tests the returned cast normal at actual impact,

velocity margin at 2/4/8 m/s. It does not merely raise the guessed angle threshold.
