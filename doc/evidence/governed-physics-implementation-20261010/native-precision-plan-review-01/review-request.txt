# Retained server physics profile

The authority and lifecycle contract is [world.md](world.md). This first adapter
supports authored solid and surface geometry, baseline poses, uniform gravity,
and coherent pose/contact snapshots. Vertical revolute cuboid doors add an
ordinary close action, mechanical obstruction braking and signed blocked/closed
consequences with an atomic stopped-angle checkpoint. One local client view
can consume current poses. Governed body-state and collision queries read the
installed owner. Signed transient controls move ontology-defined rigid agents and push eligible
free dynamic bodies. Explicit rest checkpoints preserve their recovery poses;
impact occurrences remain outside this profile. Unsupported joint/checkpoint declarations fail installation visibly;
there is no silent baseline fallback.

## Installation and policy

Physics bridges are registered in every ontology's common startup base. This
allocates no simulation and grants no invocation or control rights. Compose
[quod_physics.pl](../priv/ontologies/quod_physics.pl) with the existing agent
hosting rules in the world owner. Give the selected actor explicit `can_invoke`
grants for `physics_store_request/6` and `physics_activate/3` through ordinary
signing policy. The real-owner server fixture in
[quod_physics_tests.erl](../test/quod_physics_tests.erl) supplies those grants,
a ground collider and one falling body; run `rebar3 as test eunit
--module=quod_physics_tests`.

Deploy the shared startup base through the existing release authority, with
participating validators and projection consumers on the same implementation.
Founding manifests remain immutable provenance. World rules, authority custody
and enablement remain Prolog state, installed through ordinary edits and actions.

`physics_space(World, disabled, Instance)` suppresses both hosting that physics
agent and allocating its native world. Enabling it selects only the node in the
actor's committed hosting assignment. Other nodes have no local simulator for
that assignment. Each space can select a different host.
Each space uses a dedicated physics actor in this profile; sharing one actor
between independently enabled spaces is unsupported. Tests cover different
world-owning ontologies and independently hosted worlds in one ontology.
Existing per-predicate OCC also means activation
custody changes in one ontology can conflict across its worlds.

The Prolog selection supplies:

- `physics_run(World, Generation, IncarnationToken)` and
  `physics_structure(World, Revision)`;
- `physics_allowances(World, limits(Bodies, Poses, Contacts, CoordinateMm,
  geometry(Parts, Vertices, Triangles)),
  StepMicroseconds, GravityMmPerSecondSquared, RequestBudgetMs)`;
- `physics_body_definition(World, Id, Revision, fixed|dynamic|controlled, Pose,
  owned(Shape, DensityKgPerM3)|live(EntityRef, AssignmentRevision,
  DefinitionRevision, Digest))`;
- `physics_next_body(World, NextUnusedId)` for admission and door allocation.

This allowance schema replaces the earlier four-field `limits` term. Existing
world policy must explicitly supply geometry allowances before deployment;
this change does not migrate or wipe ontology history.

## Live definitions and atomic admission

Compose the [space transitions](spaces.md) with
`space_physical_change(W,S,Change) :- physics_space_change(W,S,Change)`.
The source entity owns `physics_definition(Entity, Revision,
geometry(Shape,Density))` and `physics_definition_allowance(Entity,CoordinateMm)`.
The destination supplies `physics_admission(World,EntityRef,Kind,Pose)` and an
authored ground `subscribes(SourceNamespace,SourceAnchor)` fact. Derived
subscription answers are not runtime declarations. Admission requires an
enabled simulation; merely classifying a space allocates no body.

`space_place/3` commits the exclusive assignment, destination admission,
source installation delegation, live body binding and structure revision in
one existing atomic transaction. The source's
`can_delegate_physics_definition(Entity,Principal,WorldRef,AuthorityRef)`
controls its exact delegation. It does not grant invocation, disclosure,
control or hosting. Each participating scope still needs its ordinary entry
ACL for the exact anchored callback. Callbacks verify the staged counterpart;
they are not independent public editing entries.

`physics_edit_definition(Entity,ExpectedRevision,geometry(Shape,Density))`
requires source `can_edit_physics_definition/2` and destination
`can_refresh_physics_definition(World,Principal,EntityRef)`. It changes the
source definition and the destination body/structure revisions and checkpoint
state atomically. This destination permission does not grant arbitrary world
editing. The binding stores an exact source reference, assignment/definition
revisions and canonical term digest, never a mutable geometry copy.

`space_withdraw/3` removes the exact body/delegation and retains the assignment
tombstone. `physics_delete_definition/2` composes that withdrawal and a

authorized binding release first in the same transaction. Body IDs never
return to the allocator. An existing world must initialize the allocator
explicitly above its authored IDs through an authorized edit.

`physics_assign_authority(World,BeforeInstance,AfterInstance)` requires world
editing permission, an already hosted successor, completed activation custody
and every source's delegation permission for that successor. It changes the
world assignment and all live source grants atomically. Host/key assignment
uses the existing agent lifecycle; replacement starts a new run generation.
This is not an inter-simulation transfer.

The runtime resolves live definitions over its existing retained verified
source projections in its bounded resource worker. Source predicate changes
wake the affected resources independently of reaction delivery. Installation
checks the exact source follow, projection height/identity and materializer
generation alongside local body/structure fences and the original deadline.
Ready subscription notices carry the exact retained reader. Selection and
installation compare its current follow row and reader lifetime locally;
they neither block on the shared log owner nor fetch or rebuild source state.
An established reader's death triggers reconstruction from the current retained
verified cache. Failure before publishing a replacement parks the source until
new progress, rather than repeatedly rebuilding the same failed input.

While a source verifies a new delta, its consuming simulation pauses without
discarding the viewer or extending input expiry. An unrelated delta resumes
the same controls. A relevant change retires the old view; missing or denied
geometry keeps its world unavailable, never turns the collider into empty
space. Independent valid worlds continue. Recovery selects current verified
state without replaying reactions. Unchanged selections do not rebuild native
geometry or write/sync storage. Geometry and installation-authorization
changes reach existing viewers through this same physics owner and its normal
refresh/installed notices. A viewer needs the world's viewing/control grants,
not entry grants to every collider source. The signed view separately retains
its actual visible-world, acting-agent, physics and Prolog authorization reads.
Hot inputs and authenticated contact matching use installed body/run fences
without reading source geometry again.

Explicit reusable door recipes produce owned geometry. They are deliberately
materialized recipes, not the default semantics of admitted live instances.
In this adapter, a live definition belongs to a different ontology with an
explicit subscription; geometry authored in the world's own scope uses owned
body definitions. Repositioning a live body revalidates its source geometry,
so the editor needs the corresponding source entry grants. An entity admitted
only to an unsimulated space has no installation delegation; its definition
can be edited without a simulated receiver consequence.

## Geometry and resource policy

`Pose` is `pose(vector(X,Y,Z), rotation(Rx,Ry,Rz))`, with millimetres and
milliradians. Rotation applies X, then Y, then Z. `vector(X,Y,Z)` authors an
identity rotation. Supported solids are `box(HalfX,HalfY,HalfZ)`, `ball(Radius)`,
`capsule(HalfSegment,Radius)` along local Y, and `convex(Vertices)` with explicit
convex-hull semantics and positive volume. `parts([part(LocalPose,Solid),...])`
authors a rigid compound: gaps between parts remain gaps, and parts have their
own position and orientation. Articulated geometry requires supported joints;
it is not flattened into a hull or replaced with a capsule.

Fixed bodies additionally support `surface(Vertices,Triangles)`. Vertices are
`vector/3`; each `triangle(A,B,C)` names zero-based vertex indices. Invalid or
degenerate triangles fail installation. This is an explicitly authored physical
surface, independent of rendered meshes, picking bounds and voxel indexing.
It represents sloped/non-cubic terrain without introducing a grid controller.
Surface geometry cannot be used as a moving solid body.

Governed body edits share the Prolog `physics_valid_body/6` schema for body
identity, kind, authored pose, geometry, density and coordinate allowance.
It accepts every shape above; the supported hinge requires box solids and a
`vector/3` baseline, with no authored frame or leaf rotation. Integer rotations,
density, motor scalars and dimensions must fit the adapter's finite binary32 representation;
this encoding envelope is independent of coordinate and geometry policy.
Native installation additionally checks numeric representation, convex volume,
triangle area, compound bounds and supported joint mechanics.

Geometry allowances count all installed parts, convex/surface vertices, and
surface triangles across the world, including unchanged retained bodies.
Unchanged geometry consumes its declared allowance without rebuilding native
shapes. Geometry and body revisions install together. `controlled` selects a
kinematic body; the governed motion path below applies checked poses without
movement-induced impulses to dynamic obstacles.

The limits are policy inputs, not Erlang constants. The native numeric envelope
bounds positions and physical dimensions. Gravity, velocity, density and all
other numeric values must be finite and representable as Rapier `f32`; density
is not compared to a distance allowance. IDs and body revisions use unsigned
64-bit native fields. Positive mass, dimensions and step are representation
requirements. The ordinary hosted-agent admission policy still owns actor
population and request capacity. Body/contact limits are not a hard byte or
wall-clock allocation guarantee: broad/narrow-phase pairs can grow quadratically
with the admitted body count. Policy authors must budget aggregate worlds too.

## Live Prolog physics queries

`physics_body_state(World, Body, Result)` requires the ordinary `can_invoke/4`
grant and `can_read_physics_body(World, Principal, Body)`. It returns
`body_state(Frame, Tick, body(Id,Revision), metres_seconds, Pose, Velocity)`.
`Frame` is `physics_frame(WorldRef, Authority, HostEpoch, RunGeneration,
Incarnation, Structure)`; pose rotations use `quaternion(X,Y,Z,W)`.
The owner copies its retained sample. A stale installed frame, missing body or
retired run may bind `unavailable`, never an inferred baseline. A missing owner
or failed owner call is a reasoned failure under the [proof contract](proofs.md),
distinct from that valid answer. Malformed request or policy values are errors.

`physics_motion_query(World, Body, Query, Result)` additionally uses
`can_query_physics_motion(World, Principal, Body, Query)` and
`physics_query_allowances(World, Principal,
query_allowances(SkinMm, PenetrationToleranceMm, SlideIterations,
NarrowPhaseTests, TranslationComponentMm, RotationComponentMrad))`.
Each allowance is ontology policy. Both predicates require a read-only proof;
they cannot validate staged grants or a durable edit using transient state.
Unauthorized queries fail. Their Erlang continuations require an opaque handle
created by the public predicate before evaluating ordinary Prolog policy.

Queries are `place(pose(vector(X,Y,Z),rotation(Rx,Ry,Rz)))`,
`travel(vector(Dx,Dy,Dz),angular(Ax,Ay,Az))` and
`landing(vector(X,Y,Z), ReachMm, DropMm, MinUpPermille)`. Placement rotation uses the authored
Euler convention; travel rotation is an angular displacement vector in world
coordinates. Distances/angles in inputs are millimetres/milliradians. The native travel
rotation query accepts at most pi radians per component. This is a single
bounded rotation sweep, not an unbounded spin command.

The result is `motion_query(Frame, Tick, body(Id,Revision), metres_seconds,
Answer)`. `Answer` is `clear(Pose,Checks)`,
`clipped(Pose,Contacts,Checks)`, `occupied(Body,Checks)`,
`blocked(Body,Checks)`, `no_support`, `unsupported`,
`unavailable`, `invalid`, or `exhausted`. Contacts name the collider and world
normal. Translation slides along contact surfaces; rotation stops at contact.
Slide exhaustion returns the conservative clipped pose; narrow-phase allowance
exhaustion returns no usable pose. Unsupported shape pairs fail closed.

Queries use the installed broad-phase index and current collider poses, including
doors; they do not rebuild terrain or move any body. Collider installation must
finish updating that index before queries become available. Results describe
that tick only: a clear preview is neither a movement authorization nor a future
landing guarantee. The command owner checks again at application.

## Played-agent movement

`physics_agent(World, Agent, Revision, Body, Motion)` selects an existing local
agent instance and its declared rigid body. `physics_viewpoint(World, Agent,
Name, Body, LocalPose, Tracking)` defines both position and orientation of the
camera in that body frame. There is no universal capsule or browser eye height.
The human principal may belong to another ontology and never impersonates the
controlled agent. A compound body may have arbitrary authored local parts;
unsupported articulated controllers fail closed.

`physics_control_agent(World, ExpectedEpoch, ExpectedSelection, Selection)` is
an ordinary transaction. Selection is `none` or `controlled(Agent, Viewpoint)`.
It requires `can_control_physics_agent/3` plus ordinary invocation admission,
checks exclusive target ownership, and advances an enduring binding epoch.
Release retains the epoch tombstone. A revoked holder cannot be silently
replaced while its durable binding still exists.

The first movement profile is:

```prolog
motion(free, SpeedMmPerSecond, TurnMradPerSecond, LeaseMs,
       query_limits(SkinMm, ToleranceMm, SlideIterations, NarrowPhaseTests), Capabilities)
motion(grounded(MinUpPermille), Speed, Turn, Lease, Limits, Capabilities)
```

Grounded means world-Y gravity, horizontal commanded travel and support normals
meeting the authored upward threshold. It is an explicit mechanical profile,
not an inference from agent shape. Capabilities are unique entries from
`snap(AngleMrad)`, `teleport(ReachMm, DropMm, MinUpPermille)` and `reposition`.
Unknown modes/capabilities are refused. Policy supplies speeds, lease and query
allowances; packet frequency does not multiply continuous travel distance.

The signed `control` mode (wire tag 3; `/api/goals/control`) reuses the existing
signed ingress and proof engine. Its database is read-only. The root uses the
existing distributed savepoint, and an external predicate stages at most one
indivisible transient effect in the immutable proof overlay. Only the first
surviving answer, after successful scope finalization, releases it through
`quod_effect` to the existing physics owner. Failure, abandoned branches,
negation, cut failure, expiry or proof cleanup release nothing. Ordinary read,
execute and cursor requests cannot stage this effect. This lane has no ledger,
operation journal, automatic replay or remote control forwarding.

```prolog
physics_control_input(World, control_frame(PhysicsFrame, Registration),
                      BindingEpoch, Sequence, Input, queued(Sequence)).
```

`PhysicsFrame` is the same exact frame used by live queries. Registration is
created by the current signed view and checked by the physics owner, together
with installed control configuration, authority, structure, sequence and expiry.
A refresh/disconnect revokes it and clears voluntary input, including unapplied
discrete requests. Grounded fall state survives a view disconnect or a reinstall
of the same control configuration. Changed physical geometry wakes support
checks even for a settled body. A clipped descent with no downward progress
settles mechanically; it does not make that contact a valid teleport landing.
While the physical configuration is unavailable, mechanics pause and old inputs
do not keep the step timer awake. A new view reads the retained sequence high-water mark,
including after configuration edits with the same binding; its prior result is
reported as suspended when the configuration changed. An
old registration cannot take over with a higher sequence. The browser sends one
request at a time and suspends commands after an uncertain response, without
replaying it. Proof success means queued admission; the view supplies the actual
mechanical outcome.

Inputs are `drive(vector(Vx,Vy,Vz),angular(Wx,Wy,Wz))`, `snap(AngleMrad)`,
`teleport(vector(X,Y,Z))`, and explicitly permitted
`reposition(pose(Position,Rotation))`. Drive is the latest desired velocity,
leased and applied at the server timestep. Translation stops/slides; rotational
sweeps check all parts and stop at contact. Snap may therefore stop short of its
requested angle. Teleport keeps orientation, checks the complete straight body
path against physical geometry without an added margin, then searches downward
for valid support using the authored skin. A body inside that support margin
can travel along a clear floor. Occupied destinations, blocked
paths, unsupported slopes, missing support and exhausted queries leave the pose
unchanged. Previews never authorize a later landing. A pending discrete command
cannot be overwritten before its outcome; there is no command accumulation queue.

An occupied authored spawn or collider edit does not trigger hidden
unbounded depenetration: travel is refused with `occupied`. Numerical
penetration is admitted only up to the authored query tolerance, including
contacts with dynamic bodies; it never excludes a class of physical obstacles. Explicit reposition
checks the complete destination and may repair an occupied start without a
travel path. Reposition is live motion, not a durable baseline edit. Restart
restores authored body baselines under a new run/registration, making any
correction visible. Free dynamic bodies support the rest checkpoints below; played-agent checkpoints
remain outside this profile. Durable placement changes use the ordinary authored
edit or request/observation/committed-consequence path, never a live query as
evidence inside a durable proof.

Relevant committed physical/control changes invalidate a runtime-owned shared
generation before asynchronous reinstallation. Owners stop accepting/advancing
old commands immediately on that token, coalesce invalidation notices, and
notify only installed state. Shapes, indices and the simulation resource remain
owned by the same retained physics process. No browser mesh or picking result
becomes collision authority.

local. Unknown/unavailable worlds freeze commanded travel instead of enabling
observer flight.

`view_only` supports desktop look. `tracking(view_only, MaxOffsetMm)` additionally
provides a calibrated XR reference-to-mount mapping. Calibration recentres
position and heading while preserving tracked pitch and roll. Head motion is view motion;
it does not change collision shape or body position. For each delivered frame,
the owner measures a conservative clearance ball around the authored mount
against the installed world, excluding its own body and using the same query
allowance. This is sensory clearance, not a new player collider. Each tracked
eye must stay within that clearance and the authored offset allowance. Otherwise
an opaque mask asks the human to return; tracking continues behind it. Missing
clearance, missing mappings, lost tracking and unavailable authority also mask.
A moved door can reduce clearance at the next authoritative frame; this is not
a physical barrier against a human moving in their room.

Default XR mesh teleportation is disabled. On the intended Vive mapping, the
left grip plus touchpad drives smooth travel; a left-pad left/right click requests
snap turn and a forward click requests a half-range teleport in the controller's
horizontal pointing direction. The right pad owns the action menu. Menus and
workspaces suppress locomotion. Components are discovered by WebXR type; missing
components are not guessed. Teleport placement uses body-origin coordinates and
physical support, without a visual-floor ray granting permission. The current
adapter has no landing preview marker. Hardware qualification must separately
check Vive runtime/browser mappings, masking, comfort and contact feedback.

## Chair pushes and rest checkpoints

A chair is an ordinary `dynamic` body with a stable numeric body identity in its
anchored world. Its projected mark binds `body_pose(Id, BodyRevision)` to the
anchored domain subject in `depicts`; neither a mesh name nor a visual occurrence
is a physics identity. Body identities must not be recycled after deletion.
`physics_move_body/5` retains the identity and advances its body revision to the
new world structure revision.

The existing signed `control` request accepts:

```prolog
physics_control_input(World, control_frame(PhysicsFrame, Registration),
    BindingEpoch, Sequence, push(body(Id, BodyRevision), vector(X,Y,Z)), Result).
```

The caller needs an active played-agent binding/view registration, ordinary
invocation admission, `can_push_physics_body(World, Principal, Id)`, and
`physics_push_allowances(World, Principal, Id, push_limits(MaxImpulse, MaxSpeed))`.
Prolog checks eligibility, the exact dynamic-body revision, and nonzero impulse
magnitude. Hinged bodies are ineligible. Policy supplies maximum impulse in
milli-newton-seconds and maximum resulting speed in millimetres per second;
input components use milli-newton-seconds. Eligibility policy may impose domain
restrictions; the adapter does not infer reach or ownership from a rendered hit.
The native owner refuses a push whose resulting linear speed exceeds the limit,
including accumulated velocity from earlier pushes. This bound governs the
command's application, not later velocity caused by gravity or collisions.

The client helper `pushInput(id, revision, impulse)` in
[locomotion.js](../client/src/locomotion.js) accepts newton-seconds and preserves
64-bit IDs. Pass its term to the simulation connection's `command` method.
The current profile exposes this programmatic action; it does not add a desktop
or headset grab/push gesture.

The owner rechecks installed policy, world/authority/host/run/incarnation,
structure, body revision, registration, sequence and expiry at admission and
application. A committed physical or policy change invalidates old commands
before asynchronous reinstallation. Each sequence can apply once within its
binding; a fresh registration reads the retained sequence and a new run discards
all inputs. `queued(Sequence)` is admission, while the projected control feedback
reports `pushed`, `refused` or expiry. A definite proof refusal keeps the current
view available and clears the rejected discrete command; a later command has
a fresh sequence and signed request. The client keeps one request in flight,
waits for discrete feedback before sending another input, and suspends commands
on an uncertain reply. Refresh obtains a fresh authorized view and never
resubmits the lost push. Physics frames move the existing visual body without
writing its author baseline; appearance refresh and checkpoint-only installation
retain the live pose and native resource.

A durable checkpoint is explicitly requested through an ordinary action:

```prolog
physics_checkpoint_body(World, Id, ExpectedBodyRevision, ExpectedSequence, RequestId).
```

`RequestId` is 32 bytes and the initial sequence is zero. The world must be
enabled. The caller needs
`can_checkpoint_physics_body(World, Id, Principal)` and ordinary invocation
admission. The world supplies `physics_rest_policy(World, Id,
recovery(PenetrationToleranceMm, NarrowPhaseChecks))`. The action records
`physics_rest(World, Id, NextSequence, waiting(rest(NextSequence, RequestId)))`.
It never accepts a caller-supplied measured pose. Once the native body sleeps,
the current authority emits a fenced, completed-tick rest observation. Give that
actor explicit invocation grants for `physics_store_rest_request/4` and
`physics_finish_rest/1`. Their existing custody lane saves exact signed bytes,
then commits the finished request and checkpoint together:

```prolog
physics_checkpoint(World, rest_v1(Id, BodyRevision,
    source(Authority, HostEpoch, Generation, Incarnation, Structure, Tick),
    world_mm_quaternion_million,
    pose(vector(X,Y,Z), quaternion(Qx,Qy,Qz,Qw)), zero_velocity)).
```

Positions are rounded millimetres and quaternion components are rounded to
millionths; linear and angular recovery velocities are zero. The authored
`physics_body/7` remains unchanged. Only the current checkpoint is selected;
replacement cannot move backward in `(Generation, Tick)`. Each new explicit
request and renewal of expired, certainly-unsent evidence completes a new
mechanical step even for a sleeping body. Unknown signed outcomes are resolved using the original bytes, without
resubmission or a fresh checkpoint request. A saved-but-never-submitted request
can remain visibly unresolved. A new request cannot bypass active custody.

An authored `physics_move_body/5` transaction advances structure/body revision,
removes that body's checkpoint and cancels its waiting checkpoint activity
atomically. It retains old signed custody for outcome resolution until a new
explicit checkpoint request replaces it. Cancellation and the changed body
revision fence the old finish permanently, so that distinct request may proceed
even if the old backend outcome remains unknown; it never resubmits the old
action or asserts a rejection. If the
checkpoint commits first, the edit removes it; if the edit commits first, the
old checkpoint loses ordinary OCC validation. Neither ordering restores the
pre-edit pose. Editing an unrelated body keeps this chair's checkpoint but
fences any pending observation against the old world structure.

Request, custody and checkpoint commits each refresh the signed live view and
suspend voluntary inputs. The retained body pose survives these refreshes.

Owner death, runtime collapse/restart, ontology replay and host restart discard
unsaved motion and unapplied pushes. The successor must commit a fresh run
before installing the current compatible rest checkpoint, or the authored
baseline with zero velocity when no checkpoint exists. Hosted-agent recovery
selects any replacement host; uncertainty or missing commit quorum leaves the
world unavailable. Replayed facts do not replay push or checkpoint reactions.
An unresolved saved checkpoint operation is resolved, never submitted again.
Frames under the new run expose the recovery reset and reject old commands.

Rest recovery uses zero displacement: it checks all restored bodies against the
current installed geometry with the policy's bounded narrow-phase allowance
and penetration tolerance. It cannot move through a newer wall or open a closed
door to repair overlap. Bad rotation, incompatible revision, unsupported shape
checks, exhausted allowance or excessive overlap visibly fail installation;
there is no silent baseline fallback. An authorized body edit invalidates the
checkpoint and supplies a new baseline as the explicit recovery exit.

## Door actions and effective definitions

`physics_add_door(World, DoorId, FrameId, Source, Position, ExpectedStructure)`
requires `can_edit_physics(World, Principal)`. `Source` is either
`local(Name, Version)` or `class_ref(Namespace, GenesisAnchor, Name, Version)`.
The latter resolves `physics_door_class/3` through the ordinary authorized
cross-ontology proof. The action materializes the resulting versioned leaf,
frame and joint in one world transaction. The retained, local-only selector
never resolves a shared class. Later class edits do not silently change an
installed instance.

A class contains `door(FrameBox, LeafBox, Density, BaselineAngleMrad,
motor(Stiffness, Damping, MaximumTorque, ClosedToleranceMrad))`. The supported
joint rotates a dynamic cuboid around a fixed frame's vertical axis. Its
collider is the leaf cuboid; frame/leaf collision is disabled. Each leaf has
one hinge, bounded by the existing body allowance, without a separate fixed
joint-count ceiling.

`physics_close_door(World, Door, ExpectedSequence, RequestId)` requires
`can_close_physics_door/3` and a 32-byte request id. It advances an activity
sequence and commits `closing(close(Sequence, RequestId))`. The retained owner
starts the selected motor. Native mechanics brake that hinge on non-frame
contact or arrival within its closed-angle tolerance; other bodies continue.
Only Prolog interprets the sample as `blocked(OtherBody)` or `closed`.

`physics_move_body/5` edits an unconnected obstacle with expected body and
structure revisions. Its new position retains authored geometry and orientation,
including non-box and compound bodies. `physics_move_door/5` edits the whole supported joint
group, advances its revisions, invalidates its checkpoint and cancels an
active close. Both require `can_edit_physics/2`. `physics_cancel_door/3`,
authorized by `can_cancel_physics_door/3`, explicitly ends a pending close

## Observation and consequence

The runtime authenticates the current simulator PID and incarnation before
matching `react_on(observed(Sample), Goal)` through the existing Prolog event
matcher. Private `physics_observation/1` metadata is available only there; an
ordinary event with the same term conveys no simulator authority. A private
physics request selects a custodied consequence; a generic observed callback
without signed-request preparation cannot consume it. The selected
actor signs a goal containing the entire frozen sample: world/activity,
authority assignment, generation/token, structure and participating body
revisions, completed-step tick, quantized angle, one bounded contact partner
(or clear), and its original validity interval.

The actor's existing custody lane first stores those exact signed bytes and
signature with `physics_store_door_request/5`, then submits
`physics_finish_door/2`. Grant both entry actions explicitly to the physics
actor. Prolog checks authority, sample bounds, revisions, current activity and
exact signed-request binding. One existing transaction replaces closing with
the finished result, records the compatible stopped-angle checkpoint, and
emits `physics_door_finished/4`. No durable proof reads live native physics,
and sealing has no physics exemption.

The checkpoint is an insertion-only restoration input, separate from the
joint's structural identity. Selecting its own new checkpoint does not reset
a retained body. A fresh simulator restores the compatible checkpoint or
baseline, after committing its new run, without replaying the earlier reaction.
A finished or cancelled activity does not restart its motor.

Required samples use the runtime's existing bounded owned-event cursor and
actor queue. Refusal retains the unsent sample; actual queue-capacity release
wakes it. Expired unsent evidence requires another completed native step and
a new validity interval, never an extension of old signed bytes. A rejected
request can be replaced only after the ordinary server proof checks the exact
original operation's immutable, consensus-applied terminal outcome at or
before the proof's pinned height. The simulator cannot certify rejection.
Outcome notifications are scoped to that request and retained across a
concurrent resolution read.

Pending, unknown and failed resolution leave the hinge held with a visible
observation status. Recovery resolves the original saved request without
resubmitting it. A saved-but-never-submitted request may remain pending;
authorized cancellation is its explicit exit. A certainly unsent policy
refusal is visible and waits for a relevant selection change. There is no
readiness polling or retry timer, and absence never means an unobstructed door.

## Owner and recovery

The existing ontology runtime selects `physics_worlds` from its retained
snapshot. One registered `quod_physics` process per anchored WorldRef owns all
native mutation. The runtime waits for its DOWN before replacing its slot;
the registration also prevents overlap when the runtime itself restarts.
Every native operation verifies the creator PID. The runtime authenticates
selection, status, result and death messages by current PID/reference.

```mermaid
sequenceDiagram
    participant R as Existing runtime
    participant P as Simulation owner
    participant A as Hosted actor
    participant O as Ontology transaction/outcome owners
    participant N as Native resource
    R->>P: Committed selection
    P->>A: Activation through runtime admission
    A->>O: Store exact signed activation bytes/signature
    O-->>A: Certified custody commit
    A->>O: Submit original activation
    O-->>R: Committed generation and token
    O-->>P: Correlated activation result via actor/runtime
    P->>N: Create, install, complete first step
    P-->>R: Installed status
```

The activation compares the expected committed generation and exact preceding
custody record. Its original bytes/signature are committed before submission,
using the existing transaction path. A successor resolves those exact bytes
through the existing outcome service. Even if its predecessor's activation
committed, the successor must activate a fresh generation with its own token.
It never adopts the dead incarnation's generation. Result-before-selection and
selection-before-result both wait for matching evidence.

`physics_activation_status(World, OriginalRequest, Status)` derives pending,
activated or cancelled from committed custody/run facts. It is not a separately
updated “sent” flag: a crash between send and recording send would still be
ambiguous. A successor resolves the saved original operation; it does not
resubmit an uncertain activation or adopt an older incarnation's token.

Pending, unknown, timeout and an unresolved custody-write result leave physics
visibly unavailable. None means rejection. Capacity waits retain the original
absolute deadline. Confirmed unsent failure, certified terminal rejection and
failed resolution reads have distinct statuses. A newer custody or run-generation
selection that arrived before a failed reply is processed once after that reply. Explicit
resource reconciliation can re-resolve unavailable activation using the same
original request, without recreating native state. A certainly unsent attempt may
start a new request on explicit reconciliation; it does not extend its old
deadline. An uncertain custody write stays closed while its issued
generation/token/custody selection is unchanged, including when it still shows
a predecessor's completed request. `activation_custody_unresolved` means the new
custody has not been observed: if it never lands, there is no matching request
to cancel. Explicit lifecycle retirement (for example disabling then enabling
the space) permits a fresh incarnation. Any late old store still competes on
its exact prior custody and generation; it cannot overwrite the new request.
If old custody does land first, recovery resolves it and policy cancellation
provides the pending-request exit. There is no retry timer.

A stored request might never have been submitted, so an outcome need not ever
appear. `physics_cancel_activation(World, ExpectedGeneration, ExactRequest)`
provides the explicit safety exit. The current principal must satisfy
`can_cancel_physics_activation(World, Principal)` as well as ordinary entry
and signing policy. No default policy authorizes it. In one transaction it
requires ground arguments, compares current custody and the still-unactivated generation, removes that
request's activation permission, and retains its exact bytes/signature in
`physics_cancelled_request/2`. It does not assert a backend operation outcome.

Cancellation and activation conflict on ordinary OCC dependencies, including an
activation whose proof already read/staged the old state. If activation commits
first, cancellation fails. If cancellation commits first, the old request cannot
later install a world or be restored as current custody. The waiting simulator retires and its replacement
activates a fresh token/generation. Cancellation never runs automatically due
to elapsed time, absent outcome or ordinary reconciliation. Policy decides who
may invoke it, including for a certified terminal failure.

For an active world, unchanged reconciliation sends no installation message, creates no resource,
and performs no ledger fold or file write/sync. Changed body definitions install
at a step boundary: unchanged IDs keep their live state, removed IDs retire,
and changed IDs require increasing revisions and reset to their authored pose
and zero velocity. The owner completes a step before exposing a coherent frame.
Changes to engine allowances, timestep or gravity require a new run.

At most one selection is in flight to the simulator; subsequent selections
coalesce into the runtime's latest desired specification. Frames stay with the
simulator and do not enter the runtime queue each tick. One timer exists while
awake, with no elapsed-time catch-up queue. A sleeping world cancels it and does
no stepping or publishing until a changed physical input wakes it. Explicit
queries copy the retained frame rather than call Rapier again.
The timer waits the timestep rounded to milliseconds after the previous call;
simulation time advances by the fixed timestep per completed integration and
can lag wall time under load. Installing changed bodies completes an immediate
step. This profile makes no real-time cadence guarantee.

Frames contain the anchored world/authority/host-epoch/run-generation fence,
structure revision, incarnation token, completed tick, per-body revisions,
metre/second units and world coordinate space. The owner snapshot API requires the expected fence/structure. A newer tick
returns a frame; the same tick returns `unchanged`, including for a sleeping
world. A stale fence, structure or future tick is unavailable. This snapshot API
is internal; the client boundary below governs pose delivery. Neither API
provides a remotely authorized contact-proof interface.

## One client view

The ordinary browser view opens `/api/simulation` with an exact visible
space reference, representation mode and the dependencies of its signed
navigation read. Physics is selected at that space's owner. The acting agent
retains its identity and ordinary local or remote signed ingress route. Only an
active pose authority must be hosted here. There is still one native viewer;
a second receives `view_busy`.

The space defines `world_view(Instance, Mode, Marks)`, its ordinary
`can_invoke/4` policy and a pinned rendering vocabulary. The common wrapper
requires one complete, valid scene and established `space_instance/2`
classification. Composed physics policy supplies `physics_space/3`, per-world
gravity/budgets, viewing and control grants. One derived `physics_enabled/2`
rule governs native resource selection, authority hosting and live input.
Classification alone allocates nothing. The canonical signed goal is:

```prolog
Namespace::(current_ontology_identity(Namespace, Anchor),
            client_world_view(Instance, Mode, ExpectedDependencies, View)).
```

`ExpectedDependencies` is a sorted list of `dependency(Namespace, Anchor,
Height)` from the navigation proof. The wrapper visits these scopes under their
ordinary ACLs; the endpoint compares every triple with the actual signed proof
envelope before installation. Public vocabulary ontologies opting into
`public_source_query/1` expose the identity read; other owners must grant that
read explicitly. This grants neither private source access nor body control.
Direct navigation can supply an empty list. Derived navigation must retain its
complete list and reread navigation after a mismatch.

The endpoint accepts this fixed parsed goal with one named `View` variable.
It uses one monitored opening worker calling existing signed ingress; socket
cancellation, death or the original expiry reaps that worker. Another opening
waits for its death and pending subscription cleanup. No second proof executor
or alternative admission route is introduced.

The result distinguishes nonphysical, disabled, denied, recovering, unavailable
and active selections. Every selection retains actual proof dependencies and
can renew before authorization expiry. A retained controller in a space whose physical
classification was removed cannot become an observer; authorized unbinding and
withdrawal remain domain transitions. An active view checks installed state
separately from its committed selection.

Marks may mix authored transforms and body-driven `mark/7` occurrences using
`body_pose(Id, Revision)` and anchored `depicts/3`. Occurrence identity and body
identity remain distinct. The depicted subject may belong to another ontology;
that reference grants no permission there. Decorative marks need no body.
Both kinds preserve parent order. `relative(Parent, transform(...))` retains an
authored local frame; `relative(Parent, body_pose(Id, Revision))` retains the
parent while expressing the body's world pose in that parent's current frame.
Decorative children then follow the body, including their authored offsets.
Only the body pose writer updates a body-driven occurrence. Missing poses hide
that occurrence and its attached children instead of restoring an authored pose.
The world pins its ordinary `rendering_vocabulary(Namespace, Anchor)`; the
signed view proves `well_formed_scene/1` there for the shared scene budget,
descriptor schema and parent ordering. Physics adds only exact body binding.
The ordinary modelling vocabulary accepts both body-pose forms in recipes.
The selected controlled body is also projected when it has no visible mark.
The endpoint checks the complete body set against the current owner. Numeric
identities, heights and sequences use decimal strings in JSON, preserving uint64
values beyond JavaScript's safe integer range.

`open` carries `session_id`, signed `request`, `signature`, `world_namespace`
and base64url `world_anchor`. `projection` returns the signed-request digest as
`view`, `height`, `expires_ms`, marks and an explicit `selection`. An active
selection additionally carries its Prolog control configuration and current frame. Schema 1 frames carry world/authority/run/structure/tick,
metre positions, XYZW quaternions, this view's random registration, selected
control's last accepted sequence and operation outcome, and optional sensory
clearance. Other principals' inputs are not exposed.

An `ack` for the exact view and last tick releases one delivery credit. The
owner retains one latest frame, not a motion queue. Unchanged sleeping worlds
send nothing; repeated acknowledgements neither step nor write. Command outcomes
advance feedback even when the body does not move. This is transport credit,
not durable acknowledgement. The original signed expiry is enforced by server
and browser; a lost connection cannot keep an authorized view indefinitely.

The browser signs one replacement read halfway through the view's remaining
lifetime, unless the view already reaches sign-in expiry. An unchanged ready
view remains usable while that proof runs, under its original expiry. The
socket retains exact dependency subscriptions and monitors; equal proof
dependencies undergo fresh asynchronous local snapshots before replacement.
The same session, principal, anchored actor, world and goal are required. A
changed dependency, denial, expiry or failed candidate takes the ordinary
invalidation path. There is no renewal retry loop or extension of old authority.

The native owner replaces only the same socket's exact previous reference and
unchanged physical selection. It issues a new random registration and delivery
reference, retains admitted input sequences and deadlines, and waits for the
new projection acknowledgement. Old references cannot detach or acknowledge
the replacement. Browser command sequence and pending discrete-command
obligations survive renewal; uncertainty still stops control without resubmission.
An uncertain attachment closes the socket, whose death releases any registration
installed by a late local call. The socket alone owns the view expiry timer.

Durable changes, owner death, expiry and structural invalidation require a fresh
signed read. Installation waits use owner notices, not polling. The ordinary

and poses, preserving authored parents and camera mounts. Unavailable selection

A foreign scope follows the existing verifier's progress;
attachment waits for its certified height to equal the pinned read height.
Higher heights invalidate the view, lower/building states wait under the original

Logical denial retains dependencies so a later policy grant can wake the view.

Replay, runtime queue collapse, actor death, changed assignment and explicit

not repeatedly activate the same crashing selection. Normal retirement and an

## Native safety audit and port decision

The Quod adapter is independent of ontology semantics. Exact dependencies are
Rapier 0.36.0 and Rustler 0.36.2, with the complete Cargo lockfile committed;
Rapier 0.36.0 was verified as the latest stable crate on 2026-10-05 against
Cargo and the upstream changelog. Rapier's `parallel` and `simd8` features are
disabled; its normal solver still uses upstream vector math. Enable
`solver-bounds-checks`: stale solver IDs and empty contact lanes must raise an
unwind panic before unchecked solver gathers. This does not remove every
upstream unsafe operation.
Parry 0.31.1 is pinned through Cargo to the vendored, verified release source.
The [source record](../native/quod_physics/vendor/parry3d-source.json) and
[minimal patch](../native/quod_physics/vendor/parry3d.patch) identify its single
algorithm correction: shape casts retain a conservative impact when GJK cannot
prove separation. The existing shape-cast contact refinement decides approach
at time zero; composite traversal still checks every triangle and part. Raw ray
casts retain their own semantics. No second geometry query is added to Quod.
Replace this dependency patch when an upstream release supplies the correction.

There are no native worker threads, event channels, foreign callbacks or unsafe
blocks in the adapter. Upstream Rapier/Rustler and their dependencies do contain
unsafe code. This is a boundary and lifecycle audit, not a formal verification
of all upstream code. The evidence record includes a dated check of every
locked package name against a pinned RustSec advisory-database snapshot and
review of its affected version ranges.

All entry points, including creation, decoding, queries and explicit retirement,
run on dirty CPU schedulers. The mutex uses `try_lock`, never an ordinary
scheduler-blocking lock. One step is one fixed Rapier integration; it cannot
yield halfway through or be safely interrupted. Solver iterations remain
Rapier's finite defaults. The benchmark includes both separated cuboids and
a densely overlapping case; body count alone does not predict cost.

The resource owns its entire Rapier graph. No Erlang term, environment or borrowed
input pointer survives a NIF call. A bounded list decoder checks the body
allowance before allocating another decoded row. Full validation precedes
mutation. Sampling allocates at most the actual admitted bodies and configured
active solver-contact pair output count, with finite checks before returning a
complete snapshot. These are Rapier contact candidates, not Prolog domain
consequences. An overflow returns a named failure instead of a partial snapshot. Input,
retained definitions and returned terms still occupy distinct bounded copies.
No growing pose history or contact-event channel is retained.

Typed native errors, Rapier non-finite-state quarantine and unwind panics
discard the world. The required soft-body container stays empty in this profile.
The improper-list boundary test exercises a real Rustler panic under the adapter's unwind catch,
then checks that the retired handle cannot be reused and the VM still runs.
The release uses `panic=unwind`. Allocator abort, process abort, memory corruption,
segmentation fault, double panic during unwinding and undefined behavior can
still terminate the entire BEAM. Catching unwinds does not contain those risks.

Explicit retirement frees the graph on dirty CPU. If an owner is killed without
termination, Rustler's final resource destructor runs wherever BEAM releases the
last reference; it is not guaranteed a dirty scheduler. The measured owner-death
case covers this small graph, not a general destructor latency bound. A killed
process executing a dirty NIF also cannot release that graph before the NIF
returns.

Keep the recorded in-process choice for this small, policy-admitted cuboid
profile. The fixture admits 64 bodies/64 poses/256 contact pairs, and measurements
include four simultaneous 64-body worlds. Do not infer suitability for arbitrary
untrusted geometry, unconstrained quotas or hard real-time service. If native
crash isolation is required, or measured scheduler/destructor/memory cost at the
intended policy limits is unacceptable, replace this adapter's execution boundary
with the recorded supervised-port fallback before enabling that profile. Keep
the same authority, activation custody, fences and resource owner; a second
physics domain engine is unnecessary.

Build/release hooks compile with `--locked` and atomically rename the completed
library into place, preserving any inode already mapped by a running BEAM.
Native hot-code upgrade is unsupported; a release restart loads a new library.
CI/release images install Rust
1.90.0 and package the resulting library under application `priv/native`.
Availability is an Erlang read of the retained module-load result. A missing
or incompatible library leaves the module loadable with availability false, so optional physics does not break embedded node startup. An enabled
selection reports `native_unavailable` with the retained load error before
submitting activation.
Native tests precede the normal sequential Erlang gates. Measured costs and
retained verification logs belong in the [evidence record](evidence/physics/README.md).

- Together these mean `dir·ray ≥ -1.2e-7`: the ray does not approach the separating plane.
- That is a separating certificate for the ray. It only weakens inside the `relative_eq` band, which needs at least ~10 m of travel even at the smallest admissible gap.
- So the new comment "Convergence of the bounds supplies no separating halfspace" is wrong.

**What the change does:**
- **At λ>0** (ray advanced, then grazes past an edge or corner, or runs parallel to a face beyond skin):
  - A TOI ≥ 1e-4 skips refinement.
  - It returns `ldir` as the contact normal. `ldir` is the last lower-bound plane, roughly opposite the travel.
  - The slide in `motion.rs` then removes almost all travel, which is a false head-on stop.
- **At λ=0:** separated tangent pairs are pushed into the approach sign test. Examples are a parallel diagonal wall, or trimesh/rotated shapes that pass the broad phase.

**Required:**
- Trace 03 showed only stagnation at λ=0, and the plan said not to stack fixes. Revert this hunk.
- Keep the stagnation change and the `niter == 100` change.
- If a test fails after the revert, that is another exit firing; bring its trace.

### 2. The λ=0 decider still has uncertified "miss" exits, and exit-kind evidence is missing

**Where the gap is:**

### 3. Decider accuracy is not measured against the margin at the policy envelope

**What your own probe shows:**
- On the captured triangle (subshape 2), the same GJK/contact family reported −1.5 mm with a normal tilted 0.062 rad, for a body 2.28 mm clear.
- The cause: GJK's touching tolerance scales with support magnitude, about `eps_rel × 9 m ≈ 1 cm` at these coordinates.
- This is the tool that now decides approach at TOI 0.

**Why the margin matters:**
- The test travel descends at `atan(2.725/33.3) = 0.082 rad`, leaving a 0.02 rad margin over that error.
- The descent angle falls below the error in two cases:
  - grounded travel faster than about 2.7 m/s;
  - free-mode horizontal travel.
- Then a "separating" verdict lets the full travel penetrate, the final occupancy check refuses, and you get the original freeze.

**The existing test does not catch this:**
- `normal1.y > 0.99` in `target_distance_cast_finds_captured_triangle` allows 0.14 rad, so it does not guard the case.

**Required:**
- Rerun the gap sweep at the deployed policy's maximum speed, and in free mode if that mode is enabled.
- Record the decider's normal error.
- Tighten the assertion to the measured value plus margin.
- If it fails, stop for a decision; the fix belongs in the refinement owner.
- My plan review endorsed this branch as the single decider without asking for this measurement. Your probe shows it was needed.

  directional_distance or the linear shape-cast dispatcher. Nonlinear compute_toi
  uses closest_points and contact refinement. These functions are not patched.
- Ordinary narrow-phase contact generation and joint solving likewise do not
  use this public linear function. Dynamic integration, door motor/braking and
  chair recovery remain on those existing paths. The native dynamic and hinge
  regressions and the full server suites remain required.

Source searches included all Parry src, all Rapier src and all Quod native src.

// Metres, seconds and kilograms. Names and revisions remain in the Erlang owner.
// id, revision, mechanical kind, baseline pose, authored geometry, density.
type Body = (u64, u64, Kind, Transform, Geometry, f64);
type Limits = (usize, usize, usize, f64, usize, usize, usize);
type Pose = (u64, (f64, f64, f64), (f64, f64, f64, f64), (f64, f64, f64));
type Rest = (u64, u64, (geometry::V3, (f64,f64,f64,f64)), f64, usize);
type Sample = (bool, Vec<Pose>, Vec<(u64, u64)>);
// Millimetres and quaternion millionths; a sleeping body has zero velocity.
type RestSample = ((i64, i64, i64), (i64, i64, i64, i64));

// Vertical revolute cuboid profile. Each leaf has one joint; the existing
// body allowance bounds the joint set too. Restore angles are insertion inputs,
// never part of a structural definition's identity.
type Hinge = (u64, u64, u64, (f64, f64, f64), f64, (f64, f64, f64, f64));
struct InstalledHinge {
    row: Hinge,
    handle: ImpulseJointHandle,
    leaf: RigidBodyHandle,
    frame: RigidBodyHandle,
    driving: bool,
}

    fn install(&mut self, definitions: Vec<Body>) -> Result<usize, Atom> {
        if definitions.len() > self.limits.0 { return Err(atoms::body_allowance()); }
        let mut budget = geometry::Budget { coordinate: self.limits.3,
            parts: self.limits.4, vertices: self.limits.5, triangles: self.limits.6 };
        let mut seen = BTreeSet::new();
        let mut prepared = Vec::new();
        for row @ (id, revision, kind, pose, shape, density) in &definitions {
            if !seen.insert(*id) || *revision == 0 || (*density as Real) <= 0.0
                || !(*density as Real).is_finite() { return Err(atoms::invalid_body()); }
            if let Some((old, _)) = self.rows.get(id) {
                if old == row { shape.charge(&mut budget)?; continue; }
                if old.1 >= *revision { return Err(atoms::stale_revision()); }
            }
            let pose = geometry::transform(*pose,self.limits.3)?;
            let shape = shape.build(*kind,&mut budget)?;
            if *kind != Kind::Fixed {
                let mass = shape.mass_properties(*density as Real).mass();
                if !mass.is_finite() || mass <= 0.0 { return Err(atoms::invalid_body()); }
            }
            prepared.push((row.clone(),pose,shape));
        }
        let removed: Vec<_> = self.rows.keys().filter(|id| !seen.contains(id)).copied().collect();
        let changes = removed.len() + prepared.len();
        for id in removed { self.remove(id); }
        for (row,pose,shape) in prepared {
            let id = row.0;
            self.remove(id);
            let builder = match row.2 {
                Kind::Dynamic => RigidBodyBuilder::dynamic().ccd_enabled(true),
                Kind::Fixed => RigidBodyBuilder::fixed(),
                Kind::Controlled => RigidBodyBuilder::kinematic_position_based(),
            };
            let body = self.bodies.insert(builder.pose(pose));
            self.colliders.insert_with_parent(ColliderBuilder::new(shape)
                .density(row.5 as Real).user_data(id as u128),body,&mut self.bodies);
            self.rows.insert(id,(row,body));
        }
        self.changed |= changes != 0;
        self.query_ready &= changes == 0;
        Ok(changes)
    }

    // Rest state is an insertion input only. The Erlang owner sends it only
    // for newly installed body revisions, never on a checkpoint-only update.
    fn restore_rest(&mut self, rows: Vec<Rest>) -> Result<(), Atom> {
        if rows.len() > self.limits.0 { return Err(atoms::body_allowance()); }
        let mut seen = BTreeSet::new();
        for (id, rev, (p, q), tolerance, checks) in &rows {
            let Some((row, handle)) = self.rows.get(id) else { return Err(atoms::invalid_checkpoint()); };
            if row.1 != *rev || row.2 != Kind::Dynamic || !seen.insert(*id)
                || self.hinges.values().any(|h| h.row.0 == *id || h.row.2 == *id)
                || !tolerance.is_finite() || *tolerance < 0.0 || *checks == 0 {
                return Err(atoms::invalid_checkpoint());
            }
            let position = geometry::vector(*p,self.limits.3).map_err(Atom::from)?;
            let rotation = Rotation::from_xyzw(q.0 as Real,q.1 as Real,q.2 as Real,q.3 as Real);
            if !rotation.is_finite() || (rotation.length_squared()-1.0).abs() > 0.000004 {
                return Err(atoms::invalid_checkpoint());
            }
            self.bodies[*handle].set_position(rapier3d::math::Pose::from_parts(position,rotation.normalize()),false);
            self.bodies[*handle].sleep();
        }
        // Zero-displacement recovery: admit numerical contact tolerance, but
        // never depenetrate a saved chair through a newer wall or closed door.
        for (id, _, _, tolerance, checks) in &rows {
            let handle = self.rows[id].1;
            let body = &self.bodies[handle];
            let collider = &self.colliders[body.colliders()[0]];
            let mut remaining = *checks;
            for (_, other) in self.colliders.iter() {
                if other.parent() == Some(handle) { continue; }
                remaining = remaining.checked_sub(1).ok_or_else(atoms::invalid_checkpoint)?;
                let other_pose = match other.parent() {
                    Some(h) => *self.bodies[h].position() * other.position_wrt_parent().copied().unwrap_or_default(),
                    None => *other.position(),
                };
                let contact = rapier3d::parry::query::contact(body.position(),collider.shape(),
                    &other_pose,other.shape(),0.0).map_err(|_| atoms::invalid_checkpoint())?;
                if contact.is_some_and(|c| c.dist < -(*tolerance as Real)) {
                    return Err(atoms::invalid_checkpoint());
                }
            }
        }
        Ok(())
    }

    fn rest_sample(&self, id: u64, rev: u64) -> Option<RestSample> {
        let (row, handle) = self.rows.get(&id)?;
        let b = &self.bodies[*handle];
        if row.1 != rev || row.2 != Kind::Dynamic || !b.is_sleeping() { return None; }
        let p = b.translation(); let q = b.rotation();
        Some((((p.x as f64*1000.0).round() as i64,(p.y as f64*1000.0).round() as i64,
               (p.z as f64*1000.0).round() as i64),
              ((q.x as f64*1e6).round() as i64,(q.y as f64*1e6).round() as i64,
               (q.z as f64*1e6).round() as i64,(q.w as f64*1e6).round() as i64)))
    }

    fn push_body(&mut self, id:u64, rev:u64, impulse:geometry::V3, max_speed:f64) -> bool {
        let Some((row, handle)) = self.rows.get(&id) else { return false; };
        if row.1 != rev || row.2 != Kind::Dynamic
            || self.hinges.values().any(|h| h.row.0 == id || h.row.2 == id)
            || !max_speed.is_finite() || max_speed <= 0.0 || !(max_speed as Real).is_finite() { return false; }
        let Ok(impulse) = geometry::vector(impulse,Real::MAX as f64) else { return false; };
        let b = &mut self.bodies[*handle];
        let velocity = b.linvel() + impulse * b.mass().recip();
        // Policy bounds the resulting speed, so rapid signed packets cannot
        // accumulate an unbounded velocity. A refused push changes nothing.
        if !velocity.is_finite() || velocity.length() as f64 > max_speed { return false; }
        b.apply_impulse(impulse,true);
        self.changed = true;
        true
    }

    fn install_hinges(&mut self, inputs: Vec<(Hinge, f64)>) -> Result<usize, Atom> {
        let mut seen = BTreeSet::new();
        for (
            row @ (id, rev, frame, (x, y, z), baseline, (stiffness, damping, force, tolerance)),
            restore,
        ) in &inputs
        {
            let Some((leaf_row, _)) = self.rows.get(id) else {
                return Err(atoms::invalid_hinge());
            };
            let Some((frame_row, _)) = self.rows.get(frame) else {
                return Err(atoms::invalid_hinge());
            };
            if !seen.insert(*id)
                || id == frame
                || leaf_row.2 != Kind::Dynamic
                || frame_row.2 != Kind::Fixed
                || leaf_row.4.box_half_x().is_none()
                || frame_row.4.box_half_x().is_none()
                || leaf_row.3.1 != (0.0, 0.0, 0.0)
                || frame_row.3.1 != (0.0, 0.0, 0.0)
                || *rev != leaf_row.1
                || *rev != frame_row.1
                || [baseline, restore, stiffness, damping, force, tolerance]
                    .iter()
                    .any(|v| !v.is_finite() || !(**v as Real).is_finite())
                || baseline.abs() >= std::f64::consts::PI
                || restore.abs() >= std::f64::consts::PI
                || (*stiffness as Real) <= 0.0
                || (*damping as Real) <= 0.0
                || (*force as Real) <= 0.0
                || (*tolerance as Real) <= 0.0
                || *tolerance >= baseline.abs()
            {
                return Err(atoms::invalid_hinge());
            }
            if [x, y, z]
                .iter()
                .any(|v| !v.is_finite() || v.abs() > self.limits.3)
            {
                return Err(atoms::coordinate_allowance());
            }
            if let Some(old) = self.hinges.get(id) {
                if (old.row != *row && old.row.1 >= *rev)
                    || (old.row == *row && self.impulse.get(old.handle).is_none())
                {
                    return Err(atoms::stale_revision());
                }
            }
        }
        let removed: Vec<_> = self
            .hinges
            .keys()
            .filter(|id| !seen.contains(id))
            .copied()
            .collect();
        let mut changes = removed.len();
        for id in removed {
            let old = self.hinges.remove(&id).unwrap();
            self.impulse.remove(old.handle, true);
        }
        for (row @ (id, _, frame_id, (x, y, z), _, _), restore) in inputs {
            if self.hinges.get(&id).is_some_and(|old| old.row == row) {
                continue;
            }
            if let Some(old) = self.hinges.remove(&id) {
                self.impulse.remove(old.handle, true);
            }
            let (leaf_row, leaf) = &self.rows[&id];
            let leaf = *leaf;
            let frame = self.rows[&frame_id].1;
            let pivot = Vector::new(x as Real, y as Real, z as Real);
            let offset = Vector::new(leaf_row.4.box_half_x().ok_or_else(atoms::invalid_hinge)?, 0.0, 0.0);
            let rotation = rapier3d::math::rotation_from_angle(Vector::Y * restore as Real);
            let position = self.bodies[frame].translation() + pivot + rotation * offset;
            self.bodies[leaf].set_translation(position, true);
            self.bodies[leaf].set_rotation(rotation, true);
            self.bodies[leaf].set_linvel(Vector::ZERO, true);
            self.bodies[leaf].set_angvel(Vector::ZERO, true);

                .local_anchor1(pivot)
                .local_anchor2(-offset)
                .contacts_enabled(false)
                .limits([restore as Real, restore as Real]);

            self.hinges.insert(

                    row,
                    handle,
                    leaf,
                    frame,

            changes += 1;

        self.changed |= changes > 0;
        self.query_ready &= changes == 0;
        Ok(changes)
    }

    fn hinge_angle(&self, h: &InstalledHinge) -> Result<Real, Atom> {
        let joint = self
            .impulse
            .get(h.handle)
            .ok_or_else(atoms::invalid_hinge)?;
        let revolute = RevoluteJoint { data: joint.data };
        let angle = revolute.angle(
            self.bodies[h.frame].rotation(),
            self.bodies[h.leaf].rotation(),
        );
        if angle.is_finite() {
            Ok(angle)
        } else {
            Err(atoms::non_finite_state())
        }
    }

    fn drive_hinge(&mut self, id: u64, drive: bool) -> Result<(), Atom> {
        let h = self.hinges.get(&id).ok_or_else(atoms::invalid_hinge)?;
        let angle = self.hinge_angle(h)?;
        let h = self.hinges.get_mut(&id).unwrap();
        let joint = self
            .impulse
            .get_mut(h.handle, true)
            .ok_or_else(atoms::invalid_hinge)?;
        if drive {
            let limit = h.row.4.abs() as Real;
            joint.data.set_limits(JointAxis::AngX, [-limit, limit]);
            joint.data.set_motor_position(
                JointAxis::AngX,
                0.0,
                h.row.5 .0 as Real,
                h.row.5 .1 as Real,
            );
            joint
                .data
                .set_motor_max_force(JointAxis::AngX, h.row.5 .2 as Real);
        } else {
            joint.data.set_limits(JointAxis::AngX, [angle, angle]);
            joint.data.set_motor_max_force(JointAxis::AngX, 0.0);
            self.bodies[h.leaf].set_linvel(Vector::ZERO, true);
            self.bodies[h.leaf].set_angvel(Vector::ZERO, true);
        }
        h.driving = drive;
        self.changed = true;
        Ok(())
    }

    // The brake is mechanical. Only Prolog interprets the measured condition
    // as a durable blocked/closed result for an authorized activity.
    fn brake_hinges(&mut self) -> Result<(), Atom> {
        let mut stopped = BTreeSet::new();
        for (id, h) in &self.hinges {
            if h.driving && self.hinge_angle(h)?.abs() <= h.row.5 .3 as Real {
                stopped.insert(*id);
            }
        }
        for pair in self
            .narrow
            .contact_pairs()
            .filter(|p| p.has_any_active_contact())
        {
            let a = self.colliders[pair.collider1].user_data as u64;
            let b = self.colliders[pair.collider2].user_data as u64;
            for (leaf, other) in [(a, b), (b, a)] {
                if let Some(h) = self.hinges.get(&leaf) {
                    if h.driving && other != h.row.2 {
                        stopped.insert(leaf);
                    }
                }
            }
        }
        for id in stopped {
            self.drive_hinge(id, false)?;
        }
        Ok(())
    }

    fn hinge_samples(&self) -> Result<Vec<(u64, i64, bool)>, Atom> {
        self.hinges
            .iter()
            .map(|(id, h)| {
                Ok((
                    *id,
                    (self.hinge_angle(h)? as f64 * 1000.0).round() as i64,
                    h.driving,
                ))
            })
            .collect()
    }

    fn remove(&mut self, id: u64) {
        if let Some((_, handle)) = self.rows.remove(&id) {
            self.bodies.remove(
                handle,
                &mut self.islands,
                &mut self.colliders,
                &mut self.impulse,
                &mut self.multibody,
                &mut self.soft,
                true,
            );
        }
    }

    fn active(&self) -> bool {
        self.changed
            || self
                .bodies
                .iter()
                .any(|(_, b)| b.is_dynamic() && !b.is_sleeping())
    }

    fn step(&mut self) -> Result<Sample, Atom> {
        if !self.active() {
            return Ok((false, vec![], vec![]));
        }
        let parameters = IntegrationParameters {
            dt: self.dt,
            ..Default::default()
        };
        self.pipeline.step(
            Vector::new(0.0, self.gravity, 0.0),
            &parameters,
            &mut self.islands,
            &mut self.broad,
            &mut self.narrow,
            &mut self.bodies,
            &mut self.colliders,
            &mut self.impulse,
            &mut self.multibody,
            &mut self.soft,
            &mut self.ccd,
            &(),
            &(),
        );
        // Rapier repairs/disables non-finite bodies internally. Expose that
        // loss of simulation continuity as failure of this selected world.
        if !self.pipeline.quarantine().is_empty() {
            return Err(atoms::non_finite_state());
        }
        self.changed = false;
        self.query_ready = true;
        self.brake_hinges()?;
        self.sample()
    }

    fn sample(&self) -> Result<Sample, Atom> {
        if self.rows.len() > self.limits.1 {
            return Err(atoms::pose_allowance());
        }
        let mut poses = Vec::with_capacity(self.rows.len());
        for (id, (_, handle)) in &self.rows {
            let b = &self.bodies[*handle];
            let p = b.translation();
            let q = b.rotation();
            let v = b.linvel();
            if !p.is_finite() || !v.is_finite() || !q.is_finite() {
                return Err(atoms::non_finite_state());
            }
            if p.to_array().iter().any(|x| x.abs() as f64 > self.limits.3) {
                return Err(atoms::coordinate_allowance());
            }
            poses.push((
                *id,
                (p.x as f64, p.y as f64, p.z as f64),
                (q.x as f64, q.y as f64, q.z as f64, q.w as f64),
                (v.x as f64, v.y as f64, v.z as f64),
            ));
        }
        let mut contacts = Vec::new();
        for pair in self
            .narrow
            .contact_pairs()
            .filter(|p| p.has_any_active_contact())
        {
            if contacts.len() == self.limits.2 {
                return Err(atoms::contact_allowance());
            }
            contacts.push((
                self.colliders[pair.collider1].user_data as u64,
                self.colliders[pair.collider2].user_data as u64,
            ));
        }
        Ok((self.active(), poses, contacts))
    }
}

fn access<T>(
    env: Env,
    resource: ResourceArc<WorldResource>,
    f: impl FnOnce(&mut World) -> Result<T, Atom>,
) -> Result<T, Atom> {
    if env.pid() != resource.owner {
        return Err(atoms::wrong_owner());
    }
    let mut guard = match resource.world.try_lock() {
        Ok(g) => g,
        Err(TryLockError::WouldBlock) => return Err(atoms::busy()),
        Err(TryLockError::Poisoned(_)) => return Err(atoms::native_failure()),
    };
    let Some(world) = guard.as_mut() else {
        return Err(atoms::retired());
    };
    match catch_unwind(AssertUnwindSafe(|| f(world))) {
        Ok(Ok(result)) => Ok(result),
        Ok(Err(reason)) => {
            *guard = None;
            Err(reason)
        }
        Err(_) => {
            *guard = None;
            Err(atoms::native_failure())
        }
    }
}

        world.install_hinges(rows)
    })
}

    if env.pid() != resource.owner {
        return Err(rustler::Error::Term(Box::new(atoms::wrong_owner())));
    }

        Err(_) => Err(rustler::Error::Term(Box::new(atoms::busy()))),
    }

//! Authored physical geometry. No visual meshes, inferred hulls, or avatar defaults.
use rapier3d::{math::Pose, prelude::*};
use rustler::{Atom, NifTaggedEnum, NifUnitEnum};
use crate::atoms;

#[derive(Clone, Copy, Debug, PartialEq)]
pub enum Error { InvalidBody, CoordinateAllowance, GeometryAllowance }
impl From<Error> for Atom {
    fn from(error: Error) -> Self {
        match error {
            Error::InvalidBody => atoms::invalid_body(),
            Error::CoordinateAllowance => atoms::coordinate_allowance(),
            Error::GeometryAllowance => atoms::geometry_allowance(),
        }
    }
}

pub type V3 = (f64, f64, f64);
pub type Transform = (V3, V3);

#[derive(Clone, Copy, Debug, PartialEq, NifUnitEnum)]
pub enum Kind { Fixed, Dynamic, Controlled }

#[derive(Clone, Debug, PartialEq, NifTaggedEnum)]
pub enum Primitive {
    Box(f64, f64, f64),
    Ball(f64),
    Capsule(f64, f64), // Half segment length along local Y, then radius.
    Convex(Vec<V3>),    // Explicitly authored convex hull semantics.
}

#[derive(Clone, Debug, PartialEq, NifTaggedEnum)]
pub enum Geometry {
    Solid(Primitive),
    Parts(Vec<(Transform, Primitive)>),
    Surface(Vec<V3>, Vec<(u32, u32, u32)>),
}

pub fn vector(v: V3, limit: f64) -> Result<Vector, Error> {
    let a = [v.0, v.1, v.2];
    if a.iter().any(|x| !x.is_finite() || x.abs() > limit || !(*x as Real).is_finite()) {
        return Err(Error::CoordinateAllowance);
    }
    Ok(Vector::new(v.0 as Real, v.1 as Real, v.2 as Real))
}

pub fn transform((p, r): Transform, limit: f64) -> Result<Pose, Error> {
    let p = vector(p, limit)?;
    let r = vector(r, Real::MAX as f64)?;
    // Same convention as authored rendering transforms: local X, then Y, then Z.
    let q = Rotation::from_rotation_z(r.z) * Rotation::from_rotation_y(r.y)
        * Rotation::from_rotation_x(r.x);
    Ok(Pose::from_parts(p, q))
}

pub struct Budget {
    pub parts: usize,
    pub vertices: usize,
    pub triangles: usize,
    pub coordinate: f64,
}

fn take(left: &mut usize, count: usize) -> Result<(), Error> {
    *left = left.checked_sub(count).ok_or(Error::GeometryAllowance)?;
    Ok(())
}

impl Primitive {
    fn build(&self, budget: &mut Budget) -> Result<SharedShape, Error> {
        take(&mut budget.parts, 1)?;
        let positive = |x: f64| {
            if !x.is_finite() || x > budget.coordinate || (x as Real) <= 0.0 {
                Err(Error::InvalidBody)
            } else { Ok(x as Real) }
        };
        match self {
            Self::Box(x,y,z) => Ok(SharedShape::cuboid(positive(*x)?,positive(*y)?,positive(*z)?)),
            Self::Ball(r) => Ok(SharedShape::ball(positive(*r)?)),
            Self::Capsule(h,r) => Ok(SharedShape::capsule_y(positive(*h)?,positive(*r)?)),
            Self::Convex(points) => {
                take(&mut budget.vertices, points.len())?;
                let points = points.iter().map(|p| vector(*p,budget.coordinate)).collect::<Result<Vec<_>,_>>()?;
                let hull = SharedShape::convex_hull(&points).ok_or(Error::InvalidBody)?;
                let volume = hull.mass_properties(1.0).mass();
                if !volume.is_finite() || volume <= 0.0 { return Err(Error::InvalidBody); }
                Ok(hull)
            }
        }
    }
}

impl Geometry {
    pub fn charge(&self, budget: &mut Budget) -> Result<(), Error> {
        let mut primitive = |p: &Primitive| {
            take(&mut budget.parts,1)?;
            if let Primitive::Convex(points) = p { take(&mut budget.vertices,points.len())?; }
            Ok(())
        };
        match self {
            Self::Solid(p) => primitive(p),
            Self::Parts(parts) => { for (_,p) in parts { primitive(p)?; } Ok(()) },
            Self::Surface(points,faces) => {
                take(&mut budget.parts,1)?;
                take(&mut budget.vertices,points.len())?;
                take(&mut budget.triangles,faces.len())
            }
        }
    }

    pub fn build(&self, kind: Kind, budget: &mut Budget) -> Result<SharedShape, Error> {
        match self {
            Self::Solid(p) => p.build(budget),
            Self::Parts(parts) => {
                if parts.is_empty() { return Err(Error::InvalidBody); }
                let mut shapes = Vec::new();
                for (pose, primitive) in parts {
                    let pose = transform(*pose,budget.coordinate)?;
                    let shape = primitive.build(budget)?;
                    let bounds = shape.compute_aabb(&pose);
                    if bounds.mins.abs().max_element() as f64 > budget.coordinate
                        || bounds.maxs.abs().max_element() as f64 > budget.coordinate {
                        return Err(Error::CoordinateAllowance);
                    }
                    shapes.push((pose,shape));
                }
                Ok(SharedShape::compound(shapes))
            }
            Self::Surface(points, faces) => {
                if kind != Kind::Fixed || faces.is_empty() { return Err(Error::InvalidBody); }
                take(&mut budget.parts,1)?;
                take(&mut budget.vertices,points.len())?;
                take(&mut budget.triangles,faces.len())?;
                let points = points.iter().map(|p| vector(*p,budget.coordinate)).collect::<Result<Vec<_>,_>>()?;
                let mut indices = Vec::new();
                for &(a,b,c) in faces {
                    let [Some(pa),Some(pb),Some(pc)] = [points.get(a as usize),points.get(b as usize),points.get(c as usize)] else {
                        return Err(Error::InvalidBody);
                    };
                    let area = (*pb-*pa).cross(*pc-*pa).length_squared();
                    if !area.is_finite() || area <= 0.0 {
                        return Err(Error::InvalidBody);
                    }
                    indices.push([a,b,c]);
                }
                SharedShape::trimesh(points,indices).map_err(|_| Error::InvalidBody)
            }
        }
    }

    pub fn box_half_x(&self) -> Option<Real> {
        match self { Self::Solid(Primitive::Box(x,_,_)) => Some(*x as Real), _ => None }
    }
}

//! Collision queries over the installed world. This module never moves a body
//! or chooses an agent's permissions, speed, gravity, or locomotion mode.
use crate::{geometry::{self, Kind, Transform, V3}, World};
use rapier3d::{math::Pose, parry::{bounding_volume::{Aabb, BoundingVolume},
    query::{self, DefaultQueryDispatcher, NonlinearRigidMotion, ShapeCastOptions}, shape::Shape}, prelude::*};
use rustler::NifTaggedEnum;

#[derive(NifTaggedEnum)]
pub enum Query {
    Place(Transform),
    Travel(V3, V3),
    // Body-origin destination, maximum travel, support search, minimum upward
    // normal. Policy chooses these values; the complete body follows a clear
    // straight path, retains its orientation and lands on declared geometry.
    Land(V3, f64, f64, f64),
    // Sensory clearance around an authored body-local camera mount. This does
    // not add a collider or move the agent when a human moves their head.
    View(V3, f64),
}

// Skin, permitted numerical penetration, slide iterations, narrow-phase tests.
// All allowances are supplied by ontology policy through the owner.
pub type Limits = (f64, f64, usize, usize);
pub type Position = (V3, (f64,f64,f64,f64));

#[derive(Debug, PartialEq, NifTaggedEnum)]
pub enum Answer {
    Clear(Position, usize),
    Clipped(Position, Vec<(u64,V3)>, usize),
    Occupied(u64, usize),
    Blocked(u64, usize),
    NoSupport,
    ViewClearance(f64, usize),
    Unavailable,
    Unsupported,
    Invalid,
    Exhausted,
}

fn position(p: Pose) -> Position {
    ((p.translation.x as f64,p.translation.y as f64,p.translation.z as f64),
     (p.rotation.x as f64,p.rotation.y as f64,p.rotation.z as f64,p.rotation.w as f64))
}
fn tuple(v: Vector) -> V3 { (v.x as f64,v.y as f64,v.z as f64) }

struct Space<'a> {
    query: QueryPipeline<'a>,
    shape: &'a dyn Shape,
    checks: usize,
    remaining: usize,
    tolerance: Real,
}

impl Space<'_> {
    fn charge(&mut self) -> Result<(),Answer> {
        self.remaining = self.remaining.checked_sub(1).ok_or(Answer::Exhausted)?;
        self.checks += 1;
        Ok(())
    }

    fn occupied(&mut self, pose: Pose) -> Result<Option<u64>,Answer> {
        let query = self.query;
        for (_,other) in query.intersect_aabb_conservative(self.shape.compute_aabb(&pose)) {
            self.charge()?;
            let contact = query::contact(&pose,self.shape,other.position(),other.shape(),0.0)
                .map_err(|_| Answer::Unsupported)?;
            if contact.is_some_and(|c| c.dist < -self.tolerance) {
                return Ok(Some(other.user_data as u64));
            }
        }
        Ok(None)
    }

    fn cast(&mut self, pose: Pose, travel: Vector, turn: Vector, skin: Real)
        -> Result<Option<(Real,u64,Vector)>,Answer> {
        let motion = NonlinearRigidMotion::new(pose,Vector::ZERO,travel,turn);
        let bounds = if turn == Vector::ZERO {
            self.shape.compute_aabb(&pose).merged(&self.shape.compute_aabb(&motion.position_at_time(1.0)))
        } else {
            // A sphere around the body origin contains every rotated part,
            // including parts whose centres are offset from that origin.
            let local = self.shape.compute_local_aabb();
            let radius = local.mins.abs().max(local.maxs.abs()).length();
            Aabb::from_half_extents(pose.translation,Vector::splat(radius))
                .merged(&Aabb::from_half_extents(pose.translation+travel,Vector::splat(radius)))
        }.loosened(skin);
        let pipeline = self.query;
        let mut earliest: Option<(Real,u64,Vector)> = None;
        for (_,other) in pipeline.intersect_aabb_conservative(bounds) {
            self.charge()?;
            let hit = if turn == Vector::ZERO {
                query::cast_shapes(&pose,travel,self.shape,other.position(),Vector::ZERO,other.shape(),
                    ShapeCastOptions { max_time_of_impact: 1.0, target_distance: skin,
                        stop_at_penetration: false, compute_impact_geometry_on_penetration: true })
            } else {
                query::cast_shapes_nonlinear(&motion,self.shape,
                    &NonlinearRigidMotion::constant_position(*other.position()),other.shape(),0.0,1.0,false)
            }.map_err(|_| Answer::Unsupported)?;
            if let Some(hit) = hit {
                let normal = other.position().rotation * hit.normal2;
                if !hit.time_of_impact.is_finite() || !normal.is_finite() { return Err(Answer::Unavailable); }
                let id = other.user_data as u64;
                if earliest.is_none_or(|(time,old,_)| hit.time_of_impact < time
                    || (hit.time_of_impact == time && id < old)) {
                    earliest = Some((hit.time_of_impact,id,normal));
                }
            }
        }
        Ok(earliest)
    }
}

pub fn evaluate(world: &World, id: u64, revision: u64, input: Query, limits: Limits) -> Answer {
    match solve(world,id,revision,input,limits) { Ok(answer) | Err(answer) => answer }
}

pub fn apply(world: &mut World, id: u64, revision: u64, input: Query, limits: Limits) -> Answer {
    let answer = evaluate(world,id,revision,input,limits);
    if let Answer::Clear((p,q),_) | Answer::Clipped((p,q),_,_) = &answer {
        let handle = world.rows[&id].1;
        let pose = Pose::from_parts(Vector::new(p.0 as Real,p.1 as Real,p.2 as Real),
            Rotation::from_xyzw(q.0 as Real,q.1 as Real,q.2 as Real,q.3 as Real));
        if *world.bodies[handle].position() != pose {
            let collider = world.bodies[handle].colliders()[0];
            world.bodies[handle].set_position(pose,true);
            world.bodies[handle].set_linvel(Vector::ZERO,true);
            world.bodies[handle].set_angvel(Vector::ZERO,true);
            // Make the new transform visible to the next controlled body in
            // this same step. Rapier retains pair-change detection for its
            // next integration; no second query index is constructed.
            world.colliders[collider].set_position(pose);
            let bounds = world.colliders[collider].compute_aabb();
            world.broad.set_aabb(&IntegrationParameters {dt: world.dt,..Default::default()},collider,bounds);
            world.changed = true;
        }
    }
    answer
}

fn solve(world: &World, id: u64, revision: u64, input: Query, (skin,tolerance,iterations,checks): Limits)
    -> Result<Answer,Answer> {
    // Installation mutates collider sets before the physics step updates the
    // retained BVH. Never treat that interval as empty collision coverage.
    if !world.query_ready { return Err(Answer::Unavailable); }
    if !skin.is_finite() || skin <= 0.0 || skin > world.limits.3
        || !tolerance.is_finite() || tolerance < 0.0 || tolerance >= skin
        || iterations == 0 || checks == 0 { return Err(Answer::Invalid); }
    let Some((row,body)) = world.rows.get(&id) else { return Err(Answer::Unavailable); };
    if row.1 != revision { return Err(Answer::Unavailable); }
    if row.2 != Kind::Controlled { return Err(Answer::Unsupported); }
    let body_handle = *body;
    let body = &world.bodies[body_handle];
    let shape = world.colliders[body.colliders()[0]].shape();
    let mut space = Space { query: world.broad.as_query_pipeline(&DefaultQueryDispatcher,
        &world.bodies,&world.colliders,QueryFilter::default().exclude_rigid_body(body_handle)),
        shape, checks: 0, remaining: checks, tolerance: tolerance as Real };
    let mut pose = *body.position();
    let (mut travel,mut turn) = match input {
        Query::View(local,radius) => {
            if !radius.is_finite() || radius <= 0.0 || radius > world.limits.3 { return Err(Answer::Invalid); }
            let local = geometry::vector(local,world.limits.3).map_err(|_| Answer::Invalid)?;
            let point = pose.transform_point(local);
            let pipeline = space.query;
            let mut clearance = radius as Real;
            for (_,other) in pipeline.intersect_aabb_conservative(Aabb::from_half_extents(point,Vector::splat(clearance))) {
                space.charge()?;
                let projected = other.shape().project_point(other.position(),point,true);
                let distance = if projected.is_inside { 0.0 } else { (point-projected.point).length() };
                if !distance.is_finite() { return Err(Answer::Unavailable); }
                clearance = clearance.min(distance);
            }
            return Ok(Answer::ViewClearance((clearance-skin as Real).max(0.0) as f64,space.checks));
        }
        Query::Place(target) => {
            let target = geometry::transform(target,world.limits.3).map_err(|_| Answer::Invalid)?;
            return Ok(match space.occupied(target)? {
                Some(other) => Answer::Occupied(other,space.checks),
                None => Answer::Clear(position(target),space.checks),
            });
        }
        Query::Land(target,reach,drop,up) => {
            if !reach.is_finite() || reach <= 0.0 || reach > world.limits.3
                || !drop.is_finite() || drop <= 0.0 || drop > world.limits.3
                || !up.is_finite() || up <= 0.0 || up > 1.0 { return Err(Answer::Invalid); }
            let target = geometry::vector(target,world.limits.3).map_err(|_| Answer::Invalid)?;
            let delta = target-pose.translation;
            if delta.length() as f64 > reach { return Err(Answer::Invalid); }
            if let Some(other) = space.occupied(pose)? { return Ok(Answer::Occupied(other,space.checks)); }
            let mut landing = pose;
            landing.translation = target;
            if let Some(other) = space.occupied(landing)? { return Ok(Answer::Occupied(other,space.checks)); }
            if delta != Vector::ZERO {
                // The path tests physical geometry; only the support search uses skin.
                // A clear body already inside the support margin may travel along it.
                if let Some((_,other,_)) = space.cast(pose,delta,Vector::ZERO,0.0)? {
                    return Ok(Answer::Blocked(other,space.checks));
                }
            }
            let descent = Vector::new(0.0,-(drop as Real),0.0);
            let Some((fraction,other,normal)) = space.cast(landing,descent,Vector::ZERO,skin as Real)?
                else { return Ok(Answer::NoSupport); };
            if normal.y < up as Real { return Ok(Answer::NoSupport); }
            landing.translation += descent*fraction;
            if landing.translation.abs().max_element() as f64 > world.limits.3 { return Err(Answer::Invalid); }
            if let Some(other) = space.occupied(landing)? { return Ok(Answer::Occupied(other,space.checks)); }
            return Ok(Answer::Clipped(position(landing),vec![(other,tuple(normal))],space.checks));
        }
        Query::Travel(delta,rotation) => (
            geometry::vector(delta,world.limits.3).map_err(|_| Answer::Invalid)?,
            geometry::vector(rotation,std::f64::consts::PI).map_err(|_| Answer::Invalid)?),
    };
    if let Some(other) = space.occupied(pose)? { return Ok(Answer::Occupied(other,space.checks)); }
    if (pose.translation+travel).abs().max_element() as f64 > world.limits.3 { return Err(Answer::Invalid); }
    let mut contacts = Vec::new();
    for _ in 0..iterations {
        if travel == Vector::ZERO && turn == Vector::ZERO { break; }
        let Some((time,other,normal)) = space.cast(pose,travel,turn,skin as Real)? else {
            pose = NonlinearRigidMotion::new(pose,Vector::ZERO,travel,turn).position_at_time(1.0);
            break;
        };
        let radius = shape.compute_local_aabb().mins.abs().max(shape.compute_local_aabb().maxs.abs()).length();
        let speed_bound = travel.length()+turn.length()*radius;
        let fraction = if turn == Vector::ZERO { time }
            else { (time-(skin as Real)/speed_bound).max(0.0) };
        pose = NonlinearRigidMotion::new(pose,Vector::ZERO,travel,turn).position_at_time(fraction);
        contacts.push((other,tuple(normal)));
        travel *= 1.0-fraction;
        // Rotation stops at contact. Translation may continue along the surface.
        turn = Vector::ZERO;
        travel -= normal*travel.dot(normal).min(0.0);
        // Cover Real projection and pose-frame roundoff in Parry's approach test.
        // Subsequent casts still check every collider, including this one.
        travel += normal*(query::gjk::eps_tol().sqrt()*travel.length());
    }
    // The query never returns an overlapping endpoint, including after a
    // conservative cast or exhausted sliding iterations.
    if let Some(other) = space.occupied(pose)? { return Ok(Answer::Occupied(other,space.checks)); }
    Ok(if contacts.is_empty() { Answer::Clear(position(pose),space.checks) }
        else { Answer::Clipped(position(pose),contacts,space.checks) })
}

    fn annular_surface(walls: bool) -> Geometry {
        let mut points = Vec::new();
        for radius in [2200.0,9000.0] {
            for i in 0..24 {
                let angle = std::f64::consts::TAU*i as f64/24.0;
                let x = (radius*(angle.cos()*1000000.0).round()/1000000.0).trunc()/1000.0;
                let z = (radius*(angle.sin()*1000000.0).round()/1000000.0).trunc()/1000.0;
                points.push((x,0.0,z));
            }
        }
        let mut faces = Vec::new();
        for i in 0..24 { faces.extend([(i,24+(i+1)%24,24+i),(i,(i+1)%24,24+(i+1)%24)]); }
        if walls {
            points.extend([(3.2,0.0,-5.0),(3.2,4.0,-5.0),(3.2,4.0,5.0),(3.2,0.0,5.0),
                (-5.0,0.0,3.2),(-5.0,4.0,3.2),(5.0,4.0,3.2),(5.0,0.0,3.2)]);
            faces.extend([(48,49,50),(48,50,51),(52,53,54),(52,54,55)]);
        }
        Geometry::Surface(points,faces)
    }

        let frame = geometry::transform((offset,(0.0,0.0,roll)),1000.0).unwrap();

        ]).unwrap();
        world.step().unwrap();
        (world,frame)
    }

//! The Gilbert-Johnson-Keerthi distance algorithm.
//!
//! # What is GJK?
//!
//! The **Gilbert-Johnson-Keerthi (GJK)** algorithm is a fundamental geometric algorithm used
//! to compute the distance between two convex shapes. It's one of the most important algorithms
//! in collision detection and is used extensively in physics engines, robotics, and computer graphics.
//!
//! ## How GJK Works (Simplified)
//!
//! GJK works by operating on the **Minkowski difference** (also called Configuration Space Obstacle or CSO)
//! of two shapes. Instead of directly comparing the shapes, GJK:
//!
//! 1. Constructs a simplex (triangle in 2D, tetrahedron in 3D) within the Minkowski difference
//! 2. Iteratively refines this simplex to find the point closest to the origin
//! 3. The distance from the origin to this closest point equals the distance between the shapes
//!
//! If the origin is **inside** the Minkowski difference, the shapes are intersecting.
//! If the origin is **outside**, the distance to the closest point gives the separation distance.
//!
//! ## When is GJK Used?
//!
//! GJK is used whenever you need to:
//! - **Check if two convex shapes intersect** (collision detection)
//! - **Find the minimum distance** between two convex shapes
//! - **Compute closest points** on two shapes
//! - **Cast a shape along a direction** to find the time of impact (continuous collision detection)
//!
//! ## Key Advantages of GJK
//!
//! - Works with **any convex shape** that can provide a support function
//! - Does **not require the full geometry** of the shapes (only support points)
//! - Very **fast convergence** in most practical cases
//! - Forms the basis for many collision detection systems
//!
//! ## Limitations
//!
//! - Only works with **convex shapes** (use convex decomposition for concave shapes)
//! - When shapes are penetrating, GJK can only detect intersection but not penetration depth
//!   (use EPA - Expanding Polytope Algorithm - for penetration depth)
//!
//! # Main Functions in This Module
//!
//! - [`closest_points`] - The core GJK algorithm for finding distance and closest points
//! - [`project_origin`] - Projects the origin onto a shape's boundary
//! - [`cast_local_ray`] - Casts a ray against a shape (used for raycasting)
//! - [`directional_distance`] - Computes how far a shape can move before touching another
//!
//! # Example

//! See individual function documentation for usage examples.

/// Results of the GJK algorithm.
///
/// This enum represents the different outcomes when running the GJK algorithm to find
/// the distance between two shapes. The result depends on whether the shapes are intersecting,
/// how far apart they are, and what information was requested.
///
/// # Understanding the Results
///
/// - **Intersection**: The shapes are overlapping. The origin lies inside the Minkowski difference.
/// - **ClosestPoints**: The exact closest points on both shapes were computed, along with the
///   separation direction.
/// - **Proximity**: The shapes are close but not intersecting. Only an approximate separation
///   direction is provided (used when exact distance computation is not needed).
/// - **NoIntersection**: The shapes are too far apart (beyond the specified `max_dist` threshold).
///
/// # Coordinate Spaces
///
/// All points and vectors in this result are expressed in the **local-space of the first shape**
/// (the shape passed as `g1` to the GJK functions). This is important when working with
/// transformed shapes.
#[derive(Clone, Debug, PartialEq)]
pub enum GJKResult {
    /// The shapes are intersecting (overlapping).
    ///
    /// This means the origin is inside the Minkowski difference of the two shapes.
    /// GJK cannot compute penetration depth; use the EPA (Expanding Polytope Algorithm)
    /// for that purpose.
    Intersection,

    /// The closest points on both shapes were found.
    ///
    /// # Fields
    ///
    /// - First `Vector`: The closest point on the first shape (in local-space of shape 1)
    /// - Second `Vector`: The closest point on the second shape (in local-space of shape 1)
    /// - `Vector`: The unit direction vector from shape 1 to shape 2 (separation axis)
    ///
    /// This variant is returned when `exact_dist` is `true` in the GJK algorithm and the
    /// shapes are not intersecting.
    ClosestPoints(Vector, Vector, Vector),

    /// The shapes are in proximity (close but not intersecting).
    ///
    /// # Fields
    ///
    /// - `Vector`: An approximate separation axis (unit direction from shape 1 to shape 2)
    ///
    /// This variant is returned when `exact_dist` is `false` and the algorithm determines
    /// the shapes are close but not intersecting. It's faster than computing exact closest
    /// points when you only need to know if shapes are nearby.
    Proximity(Vector),

    /// The shapes are too far apart.
    ///
    /// # Fields
    ///
    /// - `Vector`: A separation axis (unit direction from shape 1 to shape 2)
    ///
    /// This variant is returned when the minimum distance between the shapes exceeds
    /// the `max_dist` parameter passed to the GJK algorithm.
    NoIntersection(Vector),
}

/// The absolute tolerance used by the GJK algorithm.
///
/// This function returns the epsilon (tolerance) value that GJK uses to determine when
/// it has converged to a solution. The tolerance affects:
///
/// - When two points are considered "close enough" to be the same
/// - When the algorithm decides it has found the minimum distance
/// - Numerical stability in edge cases
///
/// The returned value is 10 times the default machine epsilon for the current floating-point
/// precision (f32 or f64). This provides a balance between accuracy and robustness.
///
/// # Returns
///
/// The absolute tolerance value (10 * DEFAULT_EPSILON)
pub fn eps_tol() -> Real {
    let _eps = crate::math::DEFAULT_EPSILON;
    _eps * 10.0
}

/// Projects the origin onto the boundary of the given shape.
///
/// This function finds the point on the shape's surface that is closest to the origin (0, 0)
/// in 2D or (0, 0, 0) in 3D. This is useful for distance queries and collision detection
/// when you need to know the closest point on a shape.
///
/// # Important: Origin Must Be Outside
///
/// **The origin is assumed to be outside of the shape.** If the origin is inside the shape,
/// this function returns `None`. For penetrating cases, use the EPA (Expanding Polytope Algorithm)
/// instead.
///
/// # Parameters
///
/// - `m`: The position and orientation (isometry) of the shape in world space
/// - `g`: The shape to project onto (must implement `SupportMap`)
/// - `simplex`: A reusable simplex structure for the GJK algorithm. Initialize with
///   `VoronoiSimplex::new()` before first use.
///
/// # Returns
///
/// - `Some(Vector)`: The closest point on the shape's boundary, in the shape's **local space**
/// - `None`: If the origin is inside the shape
///
/// # Example
///
/// ```rust
/// # #[cfg(all(feature = "dim3", feature = "f32"))] {
/// use parry3d::shape::Ball;
/// use parry3d::query::gjk::{project_origin, VoronoiSimplex};
/// use parry3d::math::Pose;
///
/// // Create a ball at position (5, 0, 0)
/// let ball = Ball::new(1.0);
/// let position = Pose::translation(5.0, 0.0, 0.0);
///
/// // Project the origin onto the ball
/// let mut simplex = VoronoiSimplex::new();
/// if let Some(closest_point) = project_origin(&position, &ball, &mut simplex) {
///     println!("Closest point on ball: {:?}", closest_point);
///     // The point will be approximately (-1, 0, 0) in local space
///     // which is the left side of the ball facing the origin
/// }
/// # }
/// ```
///
/// # Performance Note
///
/// The `simplex` parameter can be reused across multiple calls to avoid allocations.
/// This is particularly beneficial when performing many projection queries.
pub fn project_origin<G: ?Sized + SupportMap>(
    m: &Pose,
    g: &G,
    simplex: &mut VoronoiSimplex,
) -> Option<Vector> {
    match closest_points(
        &m.inverse(),
        g,
        &ConstantOrigin,
        Real::max_value(),
        true,
        simplex,
    ) {
        GJKResult::Intersection => None,
        GJKResult::ClosestPoints(p, _, _) => Some(p),
        _ => unreachable!(),
    }
}

/// Computes the closest points between two shapes using the GJK algorithm.
///
/// This is the **core function** of the GJK implementation in Parry. It can compute:
/// - Whether two shapes are intersecting
/// - The distance between two separated shapes
/// - The closest points on both shapes
/// - An approximate separation axis when exact distance isn't needed
///
/// # How It Works
///
/// The algorithm operates on the Minkowski difference (CSO) of the two shapes and iteratively
/// builds a simplex that approximates the point closest to the origin. The algorithm terminates
/// when:
/// - The shapes are proven to intersect (origin is inside the CSO)
/// - The minimum distance is found within the tolerance
/// - The shapes are proven to be farther than `max_dist` apart
///
/// # Parameters
///
/// - `pos12`: The relative position of shape 2 with respect to shape 1. This is the isometry
///   that transforms from shape 1's space to shape 2's space.
/// - `g1`: The first shape (must implement `SupportMap`)
/// - `g2`: The second shape (must implement `SupportMap`)
/// - `max_dist`: Maximum distance to check. If shapes are farther than this, the algorithm
///   returns `GJKResult::NoIntersection` early. Use `Real::max_value()` to disable this check.
/// - `exact_dist`: Whether to compute exact closest points:
///   - `true`: Computes exact distance and returns `GJKResult::ClosestPoints`
///   - `false`: May return `GJKResult::Proximity` with only an approximate separation axis,
///     which is faster when you only need to know if shapes are nearby
/// - `simplex`: A reusable simplex structure. Initialize with `VoronoiSimplex::new()` before
///   first use. Can be reused across calls for better performance.
///
/// # Returns
///
/// Returns a [`GJKResult`] which can be:
/// - `Intersection`: The shapes are overlapping
/// - `ClosestPoints(p1, p2, normal)`: The closest points on each shape (when `exact_dist` is true)
/// - `Proximity(axis)`: An approximate separation axis (when `exact_dist` is false)
/// - `NoIntersection(axis)`: The shapes are farther than `max_dist` apart
///
/// # Example: Basic Distance Query
///
/// ```rust
/// # #[cfg(all(feature = "dim3", feature = "f32"))] {
/// use parry3d::shape::{Ball, Cuboid};
/// use parry3d::query::gjk::{closest_points, VoronoiSimplex};
/// use parry3d::math::{Pose, Vector};
///
/// // Create two shapes
/// let ball = Ball::new(1.0);
/// let cuboid = Cuboid::new(Vector::new(1.0, 1.0, 1.0));
///
/// // Position them in space
/// let pos1 = Pose::translation(0.0, 0.0, 0.0);
/// let pos2 = Pose::translation(5.0, 0.0, 0.0);
///
/// // Compute relative position
/// let pos12 = pos1.inv_mul(&pos2);
///
/// // Run GJK
/// let mut simplex = VoronoiSimplex::new();
/// let result = closest_points(
///     &pos12,
///     &ball,
///     &cuboid,
///     f32::MAX,  // No distance limit
///     true,      // Compute exact distance
///     &mut simplex,
/// );
///
/// match result {
///     parry3d::query::gjk::GJKResult::ClosestPoints(p1, p2, normal) => {
///         println!("Closest point on ball: {:?}", p1);
///         println!("Closest point on cuboid: {:?}", p2);
///         println!("Separation direction: {:?}", normal);
///         let distance = (p2 - p1).length();
///         println!("Distance: {}", distance);
///     }
///     parry3d::query::gjk::GJKResult::Intersection => {
///         println!("Shapes are intersecting!");
///     }
///     _ => {}
/// }
/// # }
/// ```
///
/// # Example: Fast Proximity Check
///
/// ```rust
/// # #[cfg(all(feature = "dim3", feature = "f32"))] {
/// use parry3d::shape::Ball;
/// use parry3d::query::gjk::{closest_points, VoronoiSimplex};
/// use parry3d::math::Pose;
///
/// let ball1 = Ball::new(1.0);
/// let ball2 = Ball::new(1.0);
/// let pos12 = Pose::translation(3.0, 0.0, 0.0);
///
/// let mut simplex = VoronoiSimplex::new();
/// let result = closest_points(
///     &pos12,
///     &ball1,
///     &ball2,
///     5.0,       // Only check up to distance 5.0
///     false,     // Don't compute exact distance
///     &mut simplex,
/// );
///
/// match result {
///     parry3d::query::gjk::GJKResult::Proximity(_axis) => {
///         println!("Shapes are close but not intersecting");
///     }
///     parry3d::query::gjk::GJKResult::Intersection => {
///         println!("Shapes are intersecting");
///     }
///     parry3d::query::gjk::GJKResult::NoIntersection(_) => {
///         println!("Shapes are too far apart (> 5.0 units)");
///     }
///     _ => {}
/// }
/// # }
/// ```
///
/// # Performance Tips
///
/// 1. Reuse the `simplex` across multiple queries to avoid allocations
/// 2. Set `exact_dist` to `false` when you only need proximity information
/// 3. Use a reasonable `max_dist` to allow early termination
/// 4. GJK converges fastest when shapes are well-separated
///
/// # Notes
///
/// - All returned points and vectors are in the local-space of shape 1
/// - The algorithm typically converges in 5-10 iterations for well-separated shapes
/// - Maximum iteration count is 100 to prevent infinite loops
pub fn closest_points<G1, G2>(
    pos12: &Pose,
    g1: &G1,
    g2: &G2,
    max_dist: Real,
    exact_dist: bool,
    simplex: &mut VoronoiSimplex,
) -> GJKResult
where
    G1: ?Sized + SupportMap,
    G2: ?Sized + SupportMap,
{
    let _eps = crate::math::DEFAULT_EPSILON;
    let _eps_tol: Real = eps_tol();
    let _eps_rel: Real = <Real as ComplexField>::sqrt(_eps_tol);

    // TODO: reset the simplex if it is empty?
    let mut proj = simplex.project_origin_and_reduce();

    let mut old_dir;

    if let Some(proj_dir) = proj.try_normalize() {
        old_dir = -proj_dir;
    } else {
        return GJKResult::Intersection;
    }

    let mut max_bound = Real::max_value();
    let mut dir;
    let mut niter = 0;
    // Tightest lower bound on the distance from the origin to the CSO: `min_bound`
    // maximized over the directions probed. Its sign classifies the origin: `> 0`
    // means separation, `~ 0` puts it on the CSO boundary (touching),
    // `< 0` bounds the penetration depth.
    let mut best_min_bound = -Real::max_value();
    // Largest CSO support magnitude seen, used to scale the tolerance below.
    let mut support_scale: Real = 0.0;
    let mut nb_perturbs = 0usize;
    const MAX_PERTURBATIONS: usize = 2 * DIM;

    loop {
        let old_max_bound = max_bound;

        let neg_proj_coords = -proj;
        let (normalized, dist) = neg_proj_coords.normalize_and_length();
        if dist > _eps_tol {
            dir = normalized;
            max_bound = dist;
        } else {
            // The origin is on the simplex.
            return GJKResult::Intersection;
        }

        if max_bound >= old_max_bound {
            if best_min_bound > 0.0 {
                // Separation certified: the converged witnesses are the answer.
                if exact_dist {
                    let (p1, p2) = result(simplex, true);
                    return GJKResult::ClosestPoints(p1, p2, old_dir); // upper bounds inconsistencies
                } else {
                    return GJKResult::Proximity(old_dir);
                }
            } else if exact_dist && best_min_bound >= -_eps_rel * support_scale {
                // Origin on the CSO boundary: the pair is touching, so the witnesses
                // describe the contact.
                let (p1, p2) = result(simplex, true);
                return GJKResult::ClosestPoints(p1, p2, old_dir);
            } else if nb_perturbs < MAX_PERTURBATIONS {
                // Try slight perturbations to avoid getting stuck into a numerical ambiguity.
                nb_perturbs += 1;
                dir = perturbed_dir(dir, nb_perturbs);
            } else {
                // The CSO reaches past the origin in every direction probed.
                return GJKResult::Intersection;
            }
        }

        let cso_point = CsoPoint::from_shapes(pos12, g1, g2, dir);
        let min_bound = -dir.dot(cso_point.point);

        assert!(min_bound.is_finite());

        best_min_bound = best_min_bound.max(min_bound);
        support_scale = support_scale.max(cso_point.point.length());

        if min_bound > max_dist {
            return GJKResult::NoIntersection(dir);
        } else if !exact_dist && min_bound > 0.0 && max_bound <= max_dist {
            return GJKResult::Proximity(old_dir);
        } else if max_bound - min_bound <= _eps_rel * max_bound {
            if exact_dist {
                let (p1, p2) = result(simplex, false);
                return GJKResult::ClosestPoints(p1, p2, dir); // the distance found has a good enough precision
            } else {
                return GJKResult::Proximity(dir);
            }
        }

        if !simplex.add_point(cso_point) {
            // See the stagnation branch above for how `best_min_bound` classifies a stall.
            if best_min_bound > 0.0 {
                if exact_dist {
                    let (p1, p2) = result(simplex, false);
                    return GJKResult::ClosestPoints(p1, p2, dir);
                } else {
                    return GJKResult::Proximity(dir);
                }
            } else if exact_dist && best_min_bound >= -_eps_rel * support_scale {
                let (p1, p2) = result(simplex, false);
                return GJKResult::ClosestPoints(p1, p2, dir);
            } else if nb_perturbs < MAX_PERTURBATIONS {
                // The duplicate support point cannot enrich the simplex; jump back to
                // the top of the loop where the stagnation branch will perturb `dir`.
                continue;
            } else {
                return GJKResult::Intersection;
            }
        }

        old_dir = dir;
        proj = simplex.project_origin_and_reduce();

        if simplex.dimension() == DIM {
            if min_bound >= _eps_tol {
                if exact_dist {
                    let (p1, p2) = result(simplex, true);
                    return GJKResult::ClosestPoints(p1, p2, old_dir);
                } else {
                    // NOTE: previous implementation used old_proj here.
                    return GJKResult::Proximity(old_dir);
                }
            } else {
                return GJKResult::Intersection; // Vector inside of the cso.
            }
        }
        niter += 1;

        if niter == 100 {
            return GJKResult::NoIntersection(Vector::X);
        }
    }
}

/// Casts a ray against a shape using the GJK algorithm.
///
/// This function performs raycasting by testing a ray against a shape to find if and where
/// the ray intersects the shape. It uses a specialized version of GJK that works with rays.
///
/// # What is Raycasting?
///
/// Raycasting shoots a ray (infinite line starting from a point in a direction) and finds
/// where it first hits a shape. This is essential for:
/// - Mouse picking in 3D scenes
/// - Line-of-sight checks
/// - Projectile collision detection
/// - Laser/scanner simulations
///
/// # Parameters
///
/// - `shape`: The shape to cast the ray against (must implement `SupportMap`)
/// - `simplex`: A reusable simplex structure. Initialize with `VoronoiSimplex::new()`.
/// - `ray`: The ray to cast, containing an origin point and direction vector
/// - `max_time_of_impact`: Maximum distance along the ray to check. The ray will be treated
///   as a line segment of length `max_time_of_impact * ray.dir.length()`.
///
/// # Returns
///
/// - `Some((toi, normal))`: If the ray hits the shape
///   - `toi`: Time of impact - multiply by `ray.dir.length()` to get the actual distance
///   - `normal`: Surface normal at the hit point
/// - `None`: If the ray doesn't hit the shape within the maximum distance
///
/// # Example
///
/// ```rust
/// # #[cfg(all(feature = "dim3", feature = "f32"))] {
/// use parry3d::shape::Ball;
/// use parry3d::query::{Ray, gjk::{cast_local_ray, VoronoiSimplex}};
/// use parry3d::math::Vector;
///
/// // Create a ball at the origin
/// let ball = Ball::new(1.0);
///
/// // Create a ray starting at (0, 0, -5) pointing toward +Z
/// let ray = Ray::new(
///     Vector::new(0.0, 0.0, -5.0),
///     Vector::new(0.0, 0.0, 1.0)
/// );
///
/// let mut simplex = VoronoiSimplex::new();
/// if let Some((toi, normal)) = cast_local_ray(&ball, &mut simplex, &ray, f32::MAX) {
///     let hit_point = ray.point_at(toi);
///     println!("Ray hit at: {:?}", hit_point);
///     println!("Surface normal: {:?}", normal);
///     println!("Distance: {}", toi);
/// } else {
///     println!("Ray missed the shape");
/// }
/// # }
/// ```
///
/// # Notes
///
/// - The ray is specified in the local-space of the shape
/// - The returned normal points outward from the shape
/// - For normalized ray directions, `toi` equals the distance to the hit point
/// - This function is typically called by higher-level raycasting APIs
pub fn cast_local_ray<G: ?Sized + SupportMap>(
    shape: &G,
    simplex: &mut VoronoiSimplex,
    ray: &Ray,
    max_time_of_impact: Real,
) -> Option<(Real, Vector)> {
    let g2 = ConstantOrigin;
    minkowski_ray_cast(
        &Pose::IDENTITY,
        shape,
        &g2,
        ray,
        max_time_of_impact,
        simplex,
        false,
    )
}

/// Computes how far a shape can move in a direction before touching another shape.
///
/// This function answers the question: "If I move shape 1 along this direction, how far
/// can it travel before it touches shape 2?" This is useful for:
/// - Continuous collision detection (CCD)
/// - Movement planning and obstacle avoidance
/// - Computing time-of-impact for moving objects
/// - Safe navigation distances
///
/// # How It Works
///
/// The function casts shape 1 along the given direction vector and finds the first point
/// where it would contact shape 2. It returns:
/// - The distance that can be traveled
/// - The contact normal at the point of first contact
/// - The witness points (closest points) on both shapes at contact
///
/// # Parameters
///
/// - `pos12`: The relative position of shape 2 with respect to shape 1 (isometry from
///   shape 1's space to shape 2's space)
/// - `g1`: The first shape being moved (must implement `SupportMap`)
/// - `g2`: The second shape (static target, must implement `SupportMap`)
/// - `dir`: The direction vector to move shape 1 in (in local-space of shape 1)
/// - `simplex`: A reusable simplex structure. Initialize with `VoronoiSimplex::new()`.
///
/// # Returns
///
/// - `Some((distance, normal, witness1, witness2))`: If contact would occur
///   - `distance`: How far shape 1 can travel before touching shape 2
///   - `normal`: The contact normal at the point of first contact
///   - `witness1`: The contact point on shape 1 (in local-space of shape 1)
///   - `witness2`: The contact point on shape 2 (in local-space of shape 1)
/// - `None`: If no contact would occur (shapes don't intersect along this direction)
///
/// # Example
///
/// ```rust
/// # #[cfg(all(feature = "dim3", feature = "f32"))] {
/// use parry3d::shape::Ball;
/// use parry3d::query::gjk::{directional_distance, VoronoiSimplex};
/// use parry3d::math::{Pose, Vector};
///
/// // Two balls: one at origin, one at (10, 0, 0)
/// let ball1 = Ball::new(1.0);
/// let ball2 = Ball::new(1.0);
/// let pos12 = Pose::translation(10.0, 0.0, 0.0);
///
/// // Move ball1 toward ball2 along the +X axis
/// let direction = Vector::new(1.0, 0.0, 0.0);
///
/// let mut simplex = VoronoiSimplex::new();
/// if let Some((distance, normal, w1, w2)) = directional_distance(
///     &pos12,
///     &ball1,
///     &ball2,
///     direction,
///     &mut simplex
/// ) {
///     println!("Ball1 can move {} units before contact", distance);
///     println!("Contact normal: {:?}", normal);
///     println!("Contact point on ball1: {:?}", w1);
///     println!("Contact point on ball2: {:?}", w2);
///     // Expected: distance ≈ 8.0 (10.0 - 1.0 - 1.0)
/// }
/// # }
/// ```
///
/// # Use Cases
///
/// **1. Continuous Collision Detection:**
/// ```ignore
/// let movement_dir = velocity * time_step;
/// if let Some((toi, normal, _, _)) = directional_distance(...) {
///     if toi < 1.0 {
///         // Collision will occur during this timestep
///         let collision_time = toi * time_step;
///     }
/// }
/// ```
///
/// **2. Safe Movement Distance:**
/// ```ignore
/// let desired_movement = Vector::new(5.0, 0.0, 0.0);
/// if let Some((max_safe_dist, _, _, _)) = directional_distance(...) {
///     let actual_movement = desired_movement.normalize() * max_safe_dist.min(5.0);
/// }
/// ```
///
/// # Notes
///
/// - All inputs and outputs are in the local-space of shape 1
/// - If the shapes are already intersecting, the returned distance is 0.0 and witness
///   points are undefined (set to origin)
/// - The direction vector does not need to be normalized
/// - This function internally uses GJK raycasting on the Minkowski difference
pub fn directional_distance<G1, G2>(
    pos12: &Pose,
    g1: &G1,
    g2: &G2,
    dir: Vector,
    simplex: &mut VoronoiSimplex,
) -> Option<(Real, Vector, Vector, Vector)>
where
    G1: ?Sized + SupportMap,
    G2: ?Sized + SupportMap,
{
    let ray = Ray::new(Vector::ZERO, dir);
    minkowski_ray_cast(pos12, g1, g2, &ray, Real::max_value(), simplex, true).map(
        |(time_of_impact, normal)| {
            let witnesses = if !time_of_impact.is_zero() {
                result(simplex, simplex.dimension() == DIM)
            } else {
                // If there is penetration, the witness points
                // are undefined.
                (Vector::ZERO, Vector::ZERO)
            };

            (time_of_impact, normal, witnesses.0, witnesses.1)
        },
    )
}

// Ray-cast on the Minkowski Difference `g1 - pos12 * g2`.
// Shape casts keep an impact candidate on uncertain convergence; their
// dispatcher refines the contact and approach direction at a zero TOI.
fn minkowski_ray_cast<G1, G2>(
    pos12: &Pose,
    g1: &G1,
    g2: &G2,
    ray: &Ray,
    max_time_of_impact: Real,
    simplex: &mut VoronoiSimplex,
    conservative: bool,
) -> Option<(Real, Vector)>
where
    G1: ?Sized + SupportMap,
    G2: ?Sized + SupportMap,
{
    let _eps = crate::math::DEFAULT_EPSILON;
    let _eps_tol: Real = eps_tol();
    let _eps_rel: Real = <Real as ComplexField>::sqrt(_eps_tol);

    let ray_length = ray.dir.length();

    if relative_eq!(ray_length, 0.0) {
        return None;
    }

    let mut ltoi = 0.0;
    let mut curr_ray = Ray::new(ray.origin, ray.dir / ray_length);
    let dir = -curr_ray.dir;
    let mut ldir = dir;

    // Initialize the simplex.
    let support_point = CsoPoint::from_shapes(pos12, g1, g2, dir);
    simplex.reset(support_point.translate(-curr_ray.origin));

    // TODO: reset the simplex if it is empty?
    let mut proj = simplex.project_origin_and_reduce();
    let mut max_bound = Real::max_value();
    let mut dir;
    let mut niter = 0;
    let mut last_chance = false;

    loop {
        let old_max_bound = max_bound;

        let neg_proj_coords = -proj;
        let (normalized, dist) = neg_proj_coords.normalize_and_length();
        if dist > _eps_tol {
            dir = normalized;
            max_bound = dist;
        } else {
            return Some((ltoi / ray_length, ldir));
        }

        let support_point = if max_bound >= old_max_bound {
            // Stagnation does not prove separation. Shape casts keep the current
            // lower bound; ray casts try the projected point once more.
            last_chance = true;
            CsoPoint::single_point(proj + curr_ray.origin)
        } else {
            CsoPoint::from_shapes(pos12, g1, g2, dir)
        };

        if last_chance && (ltoi > 0.0 || conservative) {
            // The witnesses stay precise when large support coordinates stop the upper
            // bound from decreasing, so refine the lower bound with their separation
            // along the cast direction before accepting the impact.
            let (witness1, witness2) = result(simplex, simplex.dimension() == DIM);
            let witness_ltoi = (witness1 - witness2 - ray.origin).dot(curr_ray.dir);
            if ltoi > 0.0 && witness_ltoi.is_finite() && witness_ltoi > ltoi {
                ltoi = witness_ltoi;

                if ltoi / ray_length > max_time_of_impact {
                    return None;
                }
            }

            return Some((ltoi / ray_length, ldir));
        }

        // Clip the ray on the support halfspace (None <=> t < 0)
        // The configurations are:
        //   dir.dot(curr_ray.dir)  |   t   |               Action
        // −−−−−−−−−−−−−−−−−−−−-----+−−−−−−−+−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−−
        //          < 0             |  < 0  | Continue.
        //          < 0             |  > 0  | New lower bound, move the origin.
        //          > 0             |  < 0  | Miss. No intersection.
        //          > 0             |  > 0  | New higher bound.
        match query::details::ray_toi_with_halfspace(support_point.point, dir, &curr_ray) {
            Some(t) => {
                if dir.dot(curr_ray.dir) < 0.0 && t > 0.0 {
                    // new lower bound
                    ldir = dir;
                    ltoi += t;

                    // NOTE: we divide by ray_length instead of doing max_time_of_impact * ray_length
                    // because the multiplication may cause an overflow if max_time_of_impact is set
                    // to Real::max_value() by users that want to have an infinite ray.
                    if ltoi / ray_length > max_time_of_impact {
                        return None;
                    }

                    let shift = curr_ray.dir * t;
                    curr_ray.origin += shift;
                    max_bound = Real::max_value();
                    simplex.modify_pnts(&|pt| pt.translate_mut(-shift));
                    last_chance = false;
                }
            }
            None => {
                if dir.dot(curr_ray.dir) > _eps_tol {
                    // miss
                    return None;
                }
            }
        }

        if last_chance {
            return None;
        }

        let min_bound = -dir.dot(support_point.point - curr_ray.origin);

        assert!(min_bound.is_finite());

        if max_bound - min_bound <= _eps_rel * max_bound {
            // This is needed when using fixed-points to avoid missing
            // some castes.
            // TODO: I feel like we should always return `Some` in
            // this case, even with floating-point numbers. Though it
            // has not been sufficiently tested with floats yet to be sure.
            if cfg!(feature = "improved_fixed_point_support") {
                return Some((ltoi / ray_length, ldir));
            } else {
                return None;
            }
        }

        let _ = simplex.add_point(support_point.translate(-curr_ray.origin));
        proj = simplex.project_origin_and_reduce();

        if simplex.dimension() == DIM {
            // `min_bound` accumulates rounding errors proportional to the magnitude of the
            // support coordinates, so we scale the tolerance accordingly.
            let scale = support_point.point.length().max(curr_ray.origin.length());
            if min_bound >= _eps_tol * scale.max(1.0) {
                return None;
            } else {
                return Some((ltoi / ray_length, ldir)); // Vector inside of the cso.
            }
        }

        niter += 1;
        if niter == 100 {
            return conservative.then_some((ltoi / ray_length, ldir));
        }
    }
}

// Deterministically perturbs the unit direction `dir` to escape degenerate support
// directions that stall the GJK simplex without proving separation.
// Successive seeds cycle through ±offsets along each coordinate axis.
fn perturbed_dir(dir: Vector, seed: usize) -> Vector {
    const OFFSET: Real = 1.0e-2;
    let axis = (seed - 1) % DIM;
    let sign = if ((seed - 1) / DIM).is_multiple_of(2) {
        1.0
    } else {
        -1.0
    };
    let mut res = dir;
    res[axis] += sign * OFFSET;
    res.try_normalize().unwrap_or(dir)
}

fn result(simplex: &VoronoiSimplex, prev: bool) -> (Vector, Vector) {
    let mut res = (Vector::ZERO, Vector::ZERO);
    if prev {
        for i in 0..simplex.prev_dimension() + 1 {
            let coord = simplex.prev_proj_coord(i);
            let point = simplex.prev_point(i);
            res.0 += point.orig1 * coord;
            res.1 += point.orig2 * coord;
        }

        res
    } else {
        for i in 0..simplex.dimension() + 1 {
            let coord = simplex.proj_coord(i);
            let point = simplex.point(i);
            res.0 += point.orig1 * coord;
            res.1 += point.orig2 * coord;
        }

        res
    }
}

physical_pose({vector,_,_,_} = Position) -> {physical_vector(Position), {0.0,0.0,0.0}};

    {physical_vector(Position), physical_vector({vector,X,Y,Z})}.
physical_vector({vector,X,Y,Z}) when is_integer(X),is_integer(Y),is_integer(Z) ->
    {X/1000,Y/1000,Z/1000}.

query_input(Query,{query_limits,Skin,Tolerance,Slides,Checks})
  when is_integer(Skin),Skin > 0,is_integer(Tolerance),Tolerance >= 0,Tolerance < Skin,
       is_integer(Slides),Slides > 0,is_integer(Checks),Checks > 0 ->
    try
        Q = case Query of
            {place,Pose} -> {place,physical_pose(Pose)};
            {landing,Position,Reach,Drop,Up} -> {land,physical_vector(Position),Reach/1000,Drop/1000,Up/1000};
            {travel,Translation,{angular,X,Y,Z}} ->
                {travel,physical_vector(Translation),physical_vector({vector,X,Y,Z})}
        end,
        {ok,Q,{Skin/1000,Tolerance/1000,Slides,Checks}}
    catch error:_ -> error end;
query_input(_,_) -> error.

geometry({parts, Parts}) ->
    {parts, lists:map(fun({part,Pose,Shape}) -> {physical_pose(Pose), primitive(Shape)} end,Parts)};
geometry({surface, Vertices, Triangles}) ->
    true = lists:all(fun({triangle,A,B,C}) ->
        lists:all(fun(X) -> is_integer(X) andalso X >= 0 andalso X < (1 bsl 32) end,[A,B,C]);
        (_) -> false end,Triangles),
    {surface, [physical_vector(V) || V <- Vertices], [{A,B,C} || {triangle,A,B,C} <- Triangles]};
geometry(Shape) -> {solid, primitive(Shape)}.
primitive({box,X,Y,Z}) -> {Hx,Hy,Hz} = physical_vector({vector,X,Y,Z}), {box,Hx,Hy,Hz};
primitive({ball,R}) when is_integer(R) -> {ball,R/1000};
primitive({capsule,H,R}) when is_integer(H),is_integer(R) -> {capsule,H/1000,R/1000};
primitive({convex,Vertices}) -> {convex,[physical_vector(V) || V <- Vertices]}.

valid_run(G, Token, Custody) ->
    ((G =:= 0 andalso Token =:= none) orelse
       (is_binary(Token) andalso byte_size(Token) =:= 32)) andalso valid_custody(Custody, G).
valid_custody(none, _) -> true;
valid_custody({request, Token, Previous, Bytes, Signature}, G) ->
    is_binary(Token) andalso byte_size(Token) =:= 32 andalso
    is_integer(Previous) andalso Previous >= 0 andalso Previous =< G andalso
    is_binary(Bytes) andalso byte_size(Bytes) > 0 andalso
    is_binary(Signature) andalso byte_size(Signature) =:= 64;
valid_custody(_, _) -> false.

hinge({hinge,D,Revision,Frame,{vector,X,Y,Z},Baseline,{motor,Stiff,Damp,Force,Tolerance}},CPs,Bodies,G) ->
    {D,Revision,dynamic,_,_,_} = lists:keyfind(D,1,Bodies),
    {Frame,Revision,fixed,_,_,_} = lists:keyfind(Frame,1,Bodies),
    true = lists:all(fun is_integer/1,[X,Y,Z,Baseline,Stiff,Damp,Force,Tolerance]),
    Restore = case [CP || CP = {hinge,Id,_,_,_,_} <- CPs, Id =:= D] of
        [] -> Baseline;
        [{hinge,D,Revision,Generation,Tick,Angle}]
          when is_integer(Generation),Generation > 0,Generation =< G,
               is_integer(Tick),Tick > 0,is_integer(Angle) -> Angle
    end,
    {{D,Revision,Frame,{X/1000,Y/1000,Z/1000},Baseline/1000,
      {float(Stiff),float(Damp),float(Force),Tolerance/1000}},Restore/1000};
hinge(_,_,_,_) -> throw(unsupported_physics_profile).

activity({rest,D,Sequence,State,Custody}) ->
    {D,Activity} = activity({door,D,Sequence,State,Custody}),
    {{rest,D},Activity};
activity({door,D,Sequence,State,Custody}) when is_integer(D),is_integer(Sequence),Sequence >= 0 ->
    true = quod_wire_term:is_ground({State,Custody}),
    Key = case Custody of
        none -> none;
        {request,_,_,Bytes,Signature} ->
            {ok,#{operation_ref := {operation,_,_,Agent,Id}}} = quod_client_goal:verify(Bytes,Signature),
            {request,{Agent,Id}}
    end,
    {D,#{sequence => Sequence,state => State,request => activity_request(State),custody => Custody,outcome_key => Key}}.

activity_request({closing,R}) -> R;
activity_request({waiting,R}) -> R;
activity_request(_) -> none.

rest_checkpoint({rest_v1,D,Revision,{source,{agent_instance_ref,Ns,Anchor,_},Epoch,G,Token,Structure,Tick},
                 world_mm_quaternion_million,{pose,Position,{quaternion,X,Y,Z,Q}},zero_velocity},
                {recovery,Tolerance,Checks},Bodies,Hinges,Generation) ->
    {D,Revision,dynamic,_,_,_} = lists:keyfind(D,1,Bodies),
    true = is_binary(Ns) andalso is_binary(Anchor) andalso byte_size(Anchor) =:= 32,
    true = is_binary(Token) andalso byte_size(Token) =:= 32,
    true = is_integer(Epoch) andalso Epoch > 0 andalso is_integer(G) andalso G > 0 andalso G =< Generation,
    true = is_integer(Structure) andalso Structure >= Revision andalso is_integer(Tick) andalso Tick > 0,
    true = is_integer(Tolerance) andalso Tolerance >= 0 andalso is_integer(Checks) andalso Checks > 0,
    true = lists:all(fun(V) -> is_integer(V) andalso abs(V) =< 1000000 end,[X,Y,Z,Q]),
    true = not lists:any(fun({{Id,_,Frame,_,_,_},_}) -> Id =:= D orelse Frame =:= D end,Hinges),
    {D,Revision,{physical_vector(Position),{X/1000000,Y/1000000,Z/1000000,Q/1000000}},Tolerance/1000,Checks}.


update_observation_height(D,H,S) ->
    O = maps:get(D,S#s.observations),
    S#s{observations = (S#s.observations)#{D => O#{outcome_height => H}}}.
