# Renew the existing signed view without interrupting unchanged control

## Demonstrated failure and existing owners

The windowed desktop261-07 recording shows a 517 ms stationary interval with
ArrowUp continuously held and uninterrupted rendering near 60 fps. The signed
view expires inside that interval; a replacement arrives 302 ms later. The
current socket calls `release/1`, the physics owner disconnects its input, and
the UI rereads navigation while `update(null)` clears held keys. Movement only
resumes on the next key transition. The recording's later deliberate stop does
not overlap this interval; it remains an incomplete overall acceptance run.

`quod_client_simulation` already owns signature admission through one monitored
opening worker, exact proof dependencies, subscribe-before-snapshot installation,
expiry and cleanup. `quod_physics` owns the one viewer registration, retained
mechanical state and accepted input sequences. `connectWorldView` owns signed
reads and browser expiry; controlled navigation owns input and the authored
camera mount. These remain the owners. Prolog continues to decide all viewing,
control, resource and geometry policy through the unchanged ordinary signed
read/control predicates.

## Replacement within the existing lifecycle

1. Schedule one fresh signed `open` halfway through the remaining lifetime of
   each installed projection. This is protocol renewal, not readiness polling.
   Keep the current projection, its absolute expiry and commands usable while
   that one new read is being proved. Do not reread derived navigation merely
   because time passed: the existing navigation dependencies remain pinned in
   the signed goal and subscribed. Actual invalidation still rereads navigation.
   Only schedule renewal when a fresh read can outlive the current view under
   the existing sign-in session expiry. A session-limited view keeps its hard
   expiry; do not create an ever-shorter renewal loop or extend authentication.

2. Extend the existing opening worker to permit one candidate alongside the
   still-valid installed view. Reuse that worker path, with a distinct candidate
   timer under its original signed expiry. An overlapping open, cancellation,
   socket death or invalidation uses the existing cleanup barrier. The old view's
   expiry remains armed throughout. If it expires before replacement, release
   it, cancel the candidate and take the existing paused/fresh-read path.
   No deadline is extended and a late result cannot resurrect the retired view.

3. Retain subscriptions only when the freshly verified read has exactly the
   same request scope (authenticated session, anchored actor, anchored world,
   instance, mode and navigation goal), dependency identities/heights and ready
   owner incarnations. Reuse the existing followed readers and monitor set;
   do not unfollow/refollow an unchanged foreign projection. Changed dependencies
   take the existing release, subscribe-before-snapshot and installation path.
   Conservative world/dependency invalidation and per-predicate OCC are unchanged.
   No new transaction, diff broker, source mirror or private domain state exists.

4. Replace the internal native-owner `watch/2` call with one `watch/4` contract:
   `(OwnerPid, PreviousReferenceOrNone, ExpectedPhysicalSelection, SignedExpiry)`.
   Initial attachment uses `none`. Replacement requires the same calling socket,
   exact previous reference, live unexpired lease and unchanged complete physical
   fence/control selection. Check the runtime navigation guard and installed
   configuration again in the physical owner. A different viewer stays busy;
   wrong references, incarnation, body/binding or expired leases cannot renew.
   Replace the delivery reference and random registration atomically while
   retaining mechanical state, monitor, sequence and admitted inputs. Old queued
   frames/acks/controls then fail their old reference/registration. Never recreate
   the native resource or apply/replay an input as part of renewal.

5. Store the verified view expiry with its registration and check it in native
   control admission/delivery. Bound a newly admitted input by both its existing
   signed/Prolog lease deadline and the current viewer expiry. Replacement does
   not lengthen any accepted input deadline. The browser immediately sends a
   fresh ordinary drive level for keys still held after verified replacement;
   that is not replay of a discrete command. Preserve pending discrete sequence
   and feedback rules and fence any late old-registration request. An uncertain
   command cannot be automatically resubmitted by renewal.

6. Accept old-view frames while the candidate is pending, then switch to the
   new view ID only upon its matching verified projection. Keep a monotonically
   increasing local command sequence across renewal. The navigation adapter
   retains held keys, camera orientation and XR calibration when the actual
   world/run/body/binding/mount is unchanged; a registration change only makes
   the next drive sample due. Genuine unavailability, lost focus, revocation,
   changed selection or expired permission continues to clear/pause input.
   There is still one pose writer and no observer-flight fallback.

This is a refinement of the shared view lifecycle for every world, including
inactive/nonphysical views; it does not add a lobby path. No compatibility
branch, old watch export or redundant renewal executor remains. Predicate
selection, founding manifests and committed data formats do not change. Deploy
matching client/server code through the existing single-writer release gate;
this correction needs no ledger refound or domain-authority change.

## Required proof before release

- Native owner: continuous admitted drive survives verified replacement with
  unchanged input deadline, sequence, pose and install count; old references and
  registrations fail. Wrong caller, changed physical/control fence, expiry,
  revocation, recovery and second-viewer admission remain rejected. Discrete
  inputs are never applied twice or silently discarded by a successful renewal.
- Socket owner: an in-flight renewal retains its original expiry and current

  delayed proof, expiry/commit/owner-death races, cleanup, stale messages and

- Browser: deterministic timers and deferred signing/HTTP replies cover early

===== src/quod_client_simulation.erl =====
-module(quod_client_simulation).
-moduledoc """
One signed view of an exact space. Prolog selects its marks and permission;
the existing simulation owns current poses. Browser acknowledgements release
one delivery credit, not a replay cursor. Any durable advance closes the old
projection. Reopening requires a fresh ordinary signed read.
""".
-behaviour(cowboy_websocket).
-include("quod_client_goal_limits.hrl").
-export([init/2, websocket_init/1, websocket_handle/2, websocket_info/2, terminate/3]).

init(Req, _) ->
    {Peer, _} = cowboy_req:peer(Req),
    {cowboy_websocket, Req, #{peer => Peer},
     #{max_frame_size => 2 * ?QUOD_CLIENT_GOAL_REQUEST_BYTES + 4096}}.
websocket_init(S) -> {ok, S}.

websocket_handle({text, Bytes}, S) ->
    case decode_command(Bytes) of
        error -> {reply, {close, 1008, <<"invalid simulation request">>}, S};
        Command -> command(Command, S)
    end;
websocket_handle(_, S) -> {ok, S}.

decode_command(Bytes) ->
    try
        case json:decode(Bytes) of
            #{<<"type">> := <<"open">>, <<"session_id">> := Session64,
              <<"request">> := Request64, <<"signature">> := Signature64,
              <<"world_namespace">> := Ns, <<"world_anchor">> := Anchor64} when is_binary(Ns) ->
                Decode = fun(B) -> base64:decode(B, #{mode => urlsafe, padding => false}) end,
                <<_:256>> = Session = Decode(Session64),
                <<_:512>> = Signature = Decode(Signature64),
                <<_:256>> = Anchor = Decode(Anchor64),
                {open, Session, Decode(Request64), Signature, Ns, Anchor};
            #{<<"type">> := <<"ack">>} = Ack -> Ack;
            _ -> error
        end
    catch error:_ -> error end.

command({open, Session, Bytes, Signature, Ns, Anchor}, S0) ->
    S = release(S0),
    case maps:is_key(follow_requests,S) orelse maps:is_key(opening,S) of
        true -> reply(#{type => unavailable,reason => dependency_recovering},
                      S#{awaiting_cleanup => true});
        false -> open_request(Session,Bytes,Signature,Ns,Anchor,S)
    end;
command(#{<<"type">> := <<"ack">>, <<"view">> := View, <<"tick">> := Tick},
        S = #{view := View, pid := Pid, ref := Ref, tick := Tick}) ->
    quod_physics:ack(Pid, Ref, binary_to_integer(Tick)), {ok, S};
command(#{<<"type">> := <<"ack">>}, S) -> {ok, S};
command(_, S) -> {reply, {close, 1008, <<"invalid simulation command">>}, S}.

open_request(Session,Bytes,Signature,Ns,Anchor,S) ->
    case quod_client_goal:decode(Bytes) of
        {ok, #{mode := read, agent_namespace := Source, agent_genesis_anchor := SourceAnchor,
               not_after_ms := Expiry} = Request} ->
            case {view_request(Request,Ns,Anchor),Expiry - quod_time:now_ms()} of
                {{ok,Instance,Dependencies},Remaining} when Remaining > 0 ->
                    open_worker(Session,Bytes,Signature,Remaining,S#{namespace => Ns,anchor => Anchor,
                        source => Source,source_anchor => SourceAnchor,instance => Instance,
                        expected_dependencies => Dependencies});
                _ -> reply(#{type => unavailable, reason => invalid_view_request}, S)
            end;
        _ -> reply(#{type => unavailable, reason => invalid_view_request}, S)
    end.

open_worker(Session,Bytes,Signature,Remaining,S = #{namespace := Ns}) ->
    %% Reject a deadline outside the VM timer representation before allocating
    %% an opening worker. Ingress still owns signature/session admission.
    TimerResult = try {ok,erlang:start_timer(Remaining,self(),expired)}
                  catch error:badarg -> error end,
    case TimerResult of
        {ok,Timer} ->
            true = quod_reg:subscribe({physics, Ns}),
            Owner = self(), Ref = make_ref(), Peer = maps:get(peer,S),
            {Pid,M} = spawn_monitor(fun() ->
                receive {open,Ref} ->
                    Result = quod_client_goal_ingress:submit(read,Session,Bytes,Signature,Peer),
                    Owner ! {view_opened,Ref,Result}
                end
            end),
            _ = quod_process:kill_when_owner_dies(Owner,Pid),
            Pid ! {open,Ref},
            {ok,S#{opening => {Ref,Pid,M},timer => Timer}};
        error -> reply(#{type => unavailable,reason => invalid_view_deadline},maps:with([peer],S))
    end.

%% The endpoint accepts exactly this anchored read, not arbitrary goals which
%% could manufacture a View binding. Signature/principal admission remains in
%% the ordinary ingress. Canonical comparison is atom-safe and parser-owned.
view_request(#{goal_text := Text,parser_version := Version},Ns,Anchor) ->
    case quod_client_goal_parser:parse(Text,Version) of
        {ok,#{goal := {_,Ns,{_,{_,Ns,Anchor},
                    {_,Instance,Mode,Rows,{0}}}} = Goal,variables := [{<<"View">>,0}]}}
          when is_list(Rows) ->
            Dependencies = [{N,A,H} || {_,N,A,H} <- Rows],
            Expected = {'::',Ns,{',',{current_ontology_identity,Ns,Anchor},
                {client_world_view,Instance,Mode,[{dependency,N,A,H} || {N,A,H} <- Dependencies],{0}}}},
            case quod_wire_term:is_ground(Instance) andalso quod_wire_term:is_symbol(Mode)
                 andalso length(Dependencies) =:= length(Rows)
                 andalso quod_wire_term:encode_canonical(Goal) =:= quod_wire_term:encode_canonical(Expected)
                 andalso element(1,quod_client_result:encode({read,Dependencies,fail})) =:= ok of
                true -> {ok,Instance,Dependencies};
                false -> error
            end;
        _ -> error
    end.

open_result({ok, #{request_digest := Digest, request := #{not_after_ms := Expiry}},
             {normalized, {read, Dependencies, Outcome}}}, S) ->
    case Outcome of
        {error, _} -> reply(#{type => unavailable, reason => proof_unavailable}, release(S));
        _ ->
            Remaining = Expiry - quod_time:now_ms(),
            Expected = maps:get(expected_dependencies,S),
            Matches = lists:all(fun(D) -> lists:member(D,Dependencies) end,Expected),
            case {Remaining > 0,Matches,lists:keyfind(maps:get(source,S),1,Dependencies)} of
                {true,true,{_, SourceAnchor, _}} when SourceAnchor =:= map_get(source_anchor,S) ->
                    Pending = S#{pending => {Digest, Expiry, Outcome},
                                 heights => #{}, owners => #{}, anchors => #{},
                                 follows => #{}, dependency_monitors => #{}, dependency_names => #{},
                                 follow_requests => gen_server:reqids_new(),
                                 local_ready => #{}, snapshots => gen_server:reqids_new()},
                    case follow_dependencies(Dependencies, Pending) of
                        {ok, Followed} -> snapshot_dependencies(Followed);
                        {error, Followed} ->
                            reply(#{type => unavailable, reason => dependency_unavailable}, release(Followed))
                    end;
                {false,_,_} -> reply(#{type => unavailable, reason => expired}, release(S));
                {true,false,_} -> refresh(S,navigation_changed);
                _ -> reply(#{type => unavailable, reason => invalid_dependencies}, release(S))
            end
    end;
open_result(_, S) -> reply(#{type => unavailable, reason => view_not_authorized_or_ready}, release(S)).

%% Register every dependency before taking any current snapshot. These are
%% the scopes actually opened by the proof, including failed alternatives.
follow_dependencies([], S) -> {ok, S};
follow_dependencies([{Ns, Anchor, Height} | Rest], S) ->
    case {quod_simplex:genesis_hash(Ns),quod_reg:where({quod_prolog,Ns})} of
        {Other,_} when is_binary(Other), Other =/= Anchor -> {error,S};
        {Anchor,Pid} when is_pid(Pid) ->
            true = quod_reg:subscribe({runtime,Ns}),
            M = monitor(process,Pid),
            follow_dependencies(Rest, S#{
                heights := (maps:get(heights,S))#{Ns => Height},
                anchors := (maps:get(anchors,S))#{Ns => Anchor},
                owners := (maps:get(owners,S))#{Pid => Ns},
                local_ready := (maps:get(local_ready,S))#{Ns => false},
                dependency_monitors := (maps:get(dependency_monitors,S))#{M => Pid}});
        {KnownAnchor,undefined} ->
            case {KnownAnchor,quod_reg:where({quod_ns,Ns})} of
                {undefined,undefined} -> follow_foreign_dependency(Ns,Anchor,Height,Rest,S);
                _ ->
                    true = quod_reg:subscribe({runtime,Ns}),
                    M = quod_reg:monitor_name({quod_prolog,Ns},follow),
                    follow_dependencies(Rest,S#{
                        heights := (maps:get(heights,S))#{Ns => Height},
                        anchors := (maps:get(anchors,S))#{Ns => Anchor},
                        local_ready := (maps:get(local_ready,S))#{Ns => false},
                        dependency_names := (maps:get(dependency_names,S))#{M => Ns}})
            end;
        _ -> {error,S}
    end.

follow_foreign_dependency(Ns,Anchor,Height,Rest,S) ->
    case quod_reg:where({foreign_log,node}) of
        Pid when is_pid(Pid) ->
            M = monitor(process,Pid),
            Bound = S#{dependency_monitors :=
                (maps:get(dependency_monitors,S))#{M => Pid}},
            case quod_foreign_log:follow_request({Ns,Anchor},progress) of
                {ok, Request} ->
                    Followed = Bound#{follow_requests := gen_server:reqids_add(
                        Request,{Pid,Ns,Anchor,Height},maps:get(follow_requests,S))},
                    follow_dependencies(Rest,Followed);
                {error, _} -> {error,Bound}
            end;
        undefined -> {error,S}
    end.

%% One asynchronous snapshot per exact engine, after all subscriptions exist.
%% A busy engine cannot turn a statistics timeout into a fresh-proof loop.
snapshot_dependencies(S) ->
    case gen_server:reqids_size(maps:get(follow_requests,S)) of
        0 ->
            Requests = maps:fold(fun(Pid,Ns,Acc) ->
                gen_server:send_request(Pid,get_stats,{Pid,Ns},Acc)
            end,maps:get(snapshots,S),maps:get(owners,S)),
            resume_projection(S#{snapshots := Requests});
        _ -> {ok,S}
    end.

%% Keep pending registrations until their reply even after view cancellation:
%% only then is the owner-issued reference known and can be released. At most
%% one opening batch is retained; a new open waits for this cleanup notice.
follow_response(Message,S = #{follow_requests := Requests}) ->
    case gen_server:check_response(Message,Requests,true) of
        {Reply,{Pid,Ns,Anchor,Height},Remaining} ->
            Next = S#{follow_requests := Remaining},
            case {maps:is_key(pending,S),Reply,quod_reg:where({foreign_log,node})} of
                {true,{reply,{ok,Ref}},Pid} ->
                    snapshot_dependencies(Next#{follows :=
                        (maps:get(follows,S))#{Ref => {Ns,Anchor,Height,false}}});
                {Active,_,_} ->
                    case Reply of {reply,{ok,Ref}} -> unfollow(Ref); _ -> ok end,
                    case Active of
                        true -> reply(#{type => unavailable,reason => dependency_unavailable},release(Next));
                        false -> finish_follow_cleanup(Next)
                    end
            end;
        _ -> snapshot_response(Message,S)
    end;
follow_response(Message,S) -> snapshot_response(Message,S).

finish_follow_cleanup(S = #{follow_requests := Requests}) ->
    case gen_server:reqids_size(Requests) of
        0 ->
            finish_cleanup(maps:remove(follow_requests,S));
        _ -> {ok,S}
    end.

finish_cleanup(S) ->
    case maps:get(awaiting_cleanup,S,false) andalso
         not maps:is_key(opening,S) andalso not maps:is_key(follow_requests,S) of
        true -> refresh(S,dependency_recovered);
        false -> {ok,S}
    end.

unfollow(Ref) ->
    case quod_foreign_log:unfollow_request(Ref) of
        {ok, Request} -> _ = gen_server:receive_response(Request,0), ok;
        {error,_} -> ok
    end.

snapshot_response(Message,S = #{snapshots := Requests}) ->
    case gen_server:check_response(Message,Requests,true) of
        {{reply,#{applied := Height,readiness := Readiness}},{Pid,Ns},Remaining} ->
            Next = S#{snapshots := Remaining},
            case quod_reg:where({quod_prolog,Ns}) =:= Pid andalso
                 quod_simplex:genesis_hash(Ns) =:= maps:get(Ns,maps:get(anchors,S)) of
                true ->
                    case Readiness of
                        ready -> dependency_height(Ns,Height,Next);
                        {recovering,Recovery} -> dependency_recovering(Recovery,Next)
                    end;
                false -> refresh(Next,dependency_owner_changed)
            end;
        {{error,_},_,Remaining} -> refresh(S#{snapshots := Remaining},dependency_owner_changed);
        _ -> {ok,S}
    end;
snapshot_response(_,S) -> {ok,S}.

resume_projection(S = #{pending := {Digest, Expiry, Outcome}}) ->
    case {Expiry > quod_time:now_ms(),dependencies_ready(S)} of
        {false,_} -> reply(#{type => unavailable,reason => expired},release(S));
        {true,true} -> open_view(Outcome,Digest,Expiry,maps:remove(pending,S));
        {true,false} -> {ok,S}
    end;
resume_projection(S) -> {ok,S}.

dependencies_ready(S) ->
    gen_server:reqids_size(maps:get(follow_requests,S)) =:= 0 andalso
    gen_server:reqids_size(maps:get(snapshots,S)) =:= 0 andalso

%% The ontology's subject and the body identity remain separate. Duplicate

body_bindings(Marks, Control, #{poses := Poses}) ->
    try
        Available = maps:from_list([{{Id, R}, true} || {Id, R, world, _, _, _} <- Poses]),
        Rows = [{Mark, mark_body(Pose, Depicts)} ||
                  {mark, Mark, _, _, Pose, _, _, Depicts} <- Marks],
        true = length(Rows) =:= length(Marks),
        true = map_size(maps:from_list(Rows)) =:= length(Rows),
        true = lists:all(fun({Mark, Body}) -> is_binary(Mark) andalso
                            (Body =:= none orelse maps:is_key(Body, Available)) end, Rows),
        Controlled = case Control of
            none -> [];
            {control,_,_,{controlled_agent,_,_,Id,Revision,_,_}} ->
                true = maps:is_key({Id,Revision},Available), [{{Id,Revision},true}]
        end,
        {ok, maps:from_list(Controlled ++ [{Body, true} || {_, Body} <- Rows, Body =/= none])}
    catch error:_ -> error end.

    _ = case S of #{timer := T} -> erlang:cancel_timer(T); _ -> ok end,

        {M,Ns} <- maps:to_list(maps:get(dependency_names,S,#{}))],

                _ -> maps:with([peer,opening,follow_requests],S)
            end;
        error -> maps:with([peer,opening],S)
    end.

import { readMarks } from './marks.js'

const integer = value => typeof value === 'string' && /^(0|[1-9][0-9]*)$/.test(value)
const fence = frame => JSON.stringify([frame.world, frame.authority, frame.epoch,
  frame.generation, frame.incarnation, frame.structure])
const bodyKey = pose => `${pose.body}:${pose.revision}`

function readFrame(frame) {
  if (!frame || frame.schema !== 1 || frame.units !== 'metres_seconds' || frame.space !== 'world' ||
      ![frame.world, frame.authority, frame.incarnation].every(value => typeof value === 'string' && value.length > 0) ||
      ![frame.epoch, frame.generation, frame.structure, frame.tick].every(integer) || !Array.isArray(frame.poses)) {
    throw new Error('invalid simulation frame')
  }
  const poses = new Map()
  for (const pose of frame.poses) {
    if (!integer(pose.body) || !integer(pose.revision) || poses.has(bodyKey(pose)) ||
        !Array.isArray(pose.position) || pose.position.length !== 3 || !pose.position.every(Number.isFinite) ||
        !Array.isArray(pose.rotation) || pose.rotation.length !== 4 || !pose.rotation.every(Number.isFinite) ||
        Math.abs(Math.hypot(...pose.rotation) - 1) > 0.001) throw new Error('invalid body pose')
    poses.set(bodyKey(pose), pose)
  }
  const feedback = frame.control_state ?? null
  if (feedback !== null && (!/^(?:-1|0|[1-9][0-9]*)$/.test(feedback.sequence) ||
      typeof feedback.pending !== 'boolean' || typeof feedback.result !== 'string')) throw new Error('invalid control feedback')
  const clearance = frame.view_clearance ?? null
  if (clearance !== null && (!Number.isFinite(clearance) || clearance < 0)) throw new Error('invalid view clearance')
  return { fence: fence(frame), tick: BigInt(frame.tick), poses, feedback, clearance,
    received: performance.now(), physicalFrame: frame }
}

export function worldProjection(message) {
  const marks = readMarks(message.marks)
  if (typeof message.view !== 'string' || !integer(message.height) || !integer(message.expires_ms)) {
    throw new Error('invalid world projection')
  }
  if (!Number.isSafeInteger(Number(message.expires_ms)) || Number(message.expires_ms) <= Date.now()) {
    throw new Error('World authorization expired.')
  }
  const ordinary = { marks, view: message.view, selection: message.selection, expires: Number(message.expires_ms) }
  if (message.selection !== 'active') {
    if (!['nonphysical', 'disabled', 'denied', 'recovering', 'unavailable'].includes(message.selection) ||
        message.frame !== undefined || message.control !== undefined) throw new Error('invalid world selection')
    return { ...ordinary, poses: new Map(), control: null, feedback: null }
  }
  const current = readFrame(message.frame)
  if (marks.some(mark =>
    mark.body && (!mark.depicts?.anchor ||
    !current.poses.has(`${mark.body.id}:${mark.body.revision}`)))) throw new Error('invalid simulation projection')
  const bodies = new Set(marks.filter(mark => mark.body).map(mark => `${mark.body.id}:${mark.body.revision}`))
  const control = readControl(message.control ?? 'none')
  if (control) {
    if (typeof message.frame.registration !== 'string' || fromB64url(message.frame.registration).length !== 32) {
      throw new Error('invalid control registration')
    }
    bodies.add(`${control.body}:${control.bodyRevision}`)
    if (!current.feedback) throw new Error('missing control feedback')
  } else if (current.feedback) throw new Error('unexpected control feedback')
  if (bodies.size !== current.poses.size) throw new Error('unexpected projected body')
  if ([...bodies].some(key => !current.poses.has(key))) throw new Error('missing controlled body')
  return { ...ordinary, ...current, bodies, control }
}

export function advanceSimulation(current, message) {
  if (!current || current.selection !== 'active' || message.view !== current.view) return current
  const next = readFrame(message.frame)
  if (next.fence !== current.fence || next.tick <= current.tick) return current
  if (next.poses.size !== current.bodies.size || [...next.poses.keys()].some(key => !current.bodies.has(key))) {
    throw new Error('simulation body set changed without a projection')
  }
  return { ...current, ...next }
}

// Each open signs a fresh read. Disconnect and durable gaps discard all motion
// acceptance state. Reconnect is explicit (or follows a browser online event),
// never a readiness polling timer. Expiry refresh is requested by the server.
export function connectWorldView(identity, agent, { projection, frame, unavailable, refused = () => {}, refreshing = () => {} }, options) {
  const world = { ...options.world }
  if (typeof world.anchor === 'string') world.anchor = fromB64url(world.anchor)
  if (!world.instance) throw new Error('an exact space instance is required')
  const goal = anchoredGoal(world, compound('client_world_view', [world.instance, atom(options.mode),
    viewDependencies(options.dependencies), variable('View')]))
  const Socket = options.WebSocket ?? WebSocket
  const url = options.url ?? new URL('/api/simulation', globalThis.location.href)
  if (url instanceof URL) url.protocol = url.protocol === 'https:' ? 'wss:' : 'ws:'
  const socket = new Socket(String(url))
  let active = true, opening = 0, expected = null, current = null
  let sequence = -1n, sending = false, commandEpoch = 0, discreteSequence = null
  let expiryTimer = null
  const clearExpiry = () => { clearTimeout(expiryTimer); expiryTimer = null }
  const send = message => socket.send(JSON.stringify(message))
  async function open() {
    const version = ++opening
    clearExpiry()
    current = null
    expected = null
    commandEpoch++
    discreteSequence = null
    try {
      const request = goalRequestBytes(identity, { mode: 'read', agent, goal })
      const signature = new Uint8Array(await identity.provider.sign(request))
      const view = b64url(new Uint8Array(await crypto.subtle.digest('SHA-256', request)))
      if (!active || version !== opening) return
      expected = view
      send({ type: 'open', session_id: identity.session.session_id, request: b64url(request), signature: b64url(signature),
        world_namespace: world.namespace, world_anchor: b64url(world.anchor) })
    } catch (error) { if (active && version === opening) failed(error) }
  }
  const failed = error => { clearExpiry(); commandEpoch++; current = null; unavailable(error.message ?? String(error)) }
  async function command(input) {
    if (!active || !current?.control || sending) return false
    if (Date.now() >= current.expires) { failed(new Error('Simulation authorization expired.')); return false }
    const observed = BigInt(current.feedback.sequence)
    if (discreteSequence !== null) {
      if (observed < discreteSequence || current.feedback.pending) return false
      discreteSequence = null
    }
    sequence = (sequence > observed ? sequence : observed) + 1n
    if (input.functor !== 'drive') discreteSequence = sequence
    const epoch = commandEpoch
    const goal = movementGoal(world, current.physicalFrame, current.control, sequence, input)
    sending = true
    try {
      const reply = await signedGoal(identity, { mode: 'control', agent, goal }, options)
      if (active && epoch === commandEpoch && reply.result !== 'ok') {
        if (reply.result === 'fail') {
          discreteSequence = null
          refused('Movement was refused.', reply.reasons ?? [])
        } else failed(new Error('Movement outcome unavailable. Refresh the simulation to reconnect.'))
      }
      return reply.result === 'ok'
    } catch (error) {
      // Do not retry an uncertain command or continue with fresh commands after
      // losing its acknowledgement. A fresh view recovers the owner's sequence.
      if (active && epoch === commandEpoch) failed(error)
      return false
    } finally { sending = false }
  }
  socket.onopen = open
  socket.onmessage = event => {
    if (!active) return
    try {
      const message = JSON.parse(event.data)
      if (message.type === 'refresh') {
        commandEpoch++
        current = null
        clearExpiry()
        if (refreshing(message.reason) !== false) {
          if (message.reason === 'navigation_changed') failed(new Error('The selected space changed. Reload the view.'))
          else void open()
        }
      } else if (message.type === 'unavailable') {
        clearExpiry()
        commandEpoch++
        current = null
        unavailable(message.reason)
      } else if (message.type === 'projection' && message.view === expected) {
        commandEpoch++
        current = worldProjection(message)
        clearExpiry()
        expiryTimer = setTimeout(() => failed(new Error('Simulation authorization expired.')), Math.max(0, current.expires - Date.now()))
        sequence = current.feedback ? BigInt(current.feedback.sequence) : -1n
        current.command = command
        projection(current)
        if (current.selection === 'active') send({ type: 'ack', view: current.view, tick: String(current.tick) })
      } else if (message.type === 'simulation_frame' && current && message.view === expected) {
        const next = advanceSimulation(current, message)
        if (next !== current) { current = next; frame(current) }
        if (current.selection === 'active') send({ type: 'ack', view: current.view, tick: String(current.tick) })
      }
    } catch (error) { failed(error); socket.close() }
  }
  socket.onclose = () => { if (active) failed(new Error('Simulation disconnected. Refresh to reconnect.')) }
  socket.onerror = () => { if (active) failed(new Error('Simulation connection unavailable.')) }
  return { command, close() { clearExpiry(); active = false; opening++; commandEpoch++; current = null; socket.close() } }
}
