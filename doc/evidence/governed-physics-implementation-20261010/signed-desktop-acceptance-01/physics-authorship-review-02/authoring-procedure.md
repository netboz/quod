# Inactive source authoring: reviewed preparation boundary

This procedure is for a never-physical existing world whose authored
`physics_space/3` and `agent_host/4` sources are empty. It is not an atomic
program installation or a procedure for upgrading an active simulation.
Do not begin live publication until the complete subsequent activation,
including initial key custody, has been specified and verified.

Use the existing signed source editor, source inspection, operation journal
and outcome resolution. Keep the exact target namespace and genesis anchor
in every goal. Confirm its current source and retained native manifest;
class membership and package edits do not change that manifest. Preserve
all existing source, scene data, identity and ledger history. Stop on an
unexpected predicate baseline.

Group the unchanged `agent_instance.pl` and `quod_physics.pl` clauses by
predicate, preserving their original clause order. This puts both
`agent_hosting_suspended/1` clauses in one edit, with the failure clause first.
Publish all helper predicates before these final entry points. Their order
relative to each other is immaterial while both inactivity guards hold:

- `agent_hosting_projection/4`
- `physics_projection/2`
- `react_on/2`

Compile each edit using the existing `prolog_edit_goal/5` interface. In the
same target transaction as its expected-source check and mutation, require
the absent `physics_space/3` and `agent_host/4` predicates through ordinary
negated calls and require their authored sources to be empty. Ordinary target
symbol admission must see those callable guards. Cold source inspection by
itself does not capture an absent predicate dependency.

Submit each independent edit once. Await its original operation's terminal
outcome before another write to that predicate. Expiry, a lost response or an
absent source answer is not a rejection. Resolve an uncertain request by its
original identity; never submit a new request to resolve uncertainty.

Read the committed predicate back in canonical source form, including clause
order. Check the unchanged nonphysical view and the installed resource owners.
An empty native map alone is insufficient: source publication must cause no
resource-selection failures or unintended actor execution. The local tests
cover both incomplete and complete-program restart. After an interruption,
first resolve outstanding original requests, then inspect current verified
source to determine the next independent edit. Use no progress ledger,
history replay, polling loop or repair protocol.

Successful source authoring is not enablement. The next physical configuration
must be a complete ordinary atomic transition with its own exact source/state
guards, explicit geometry, agent/body/camera bindings, authority and host,
authorization and Prolog allowances. Measure the actual signed goal, parser
tokens, admitted symbols, diff, read set and sealed material against their
existing limits. Do not split a required physical transition to fit a limit.
Private key preparation must use the reviewed agent custody lifecycle.

Real installed-state and mechanically fulfilled placement checks follow that
commit. The independent acceptance obligations for live remote colliders,
unchanged repeat work and signed desktop collision still apply. No live edit,
new native interface, deployment, compatibility branch or refound is authorized
by this preparation evidence.
