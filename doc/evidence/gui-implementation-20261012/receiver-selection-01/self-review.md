# Independent assessment

The receiver address is bound to the exact agent bytes from verified signed-read
admission, not to a caller claim or a session key alone. The HUD source must be
the agent's own anchored ontology. A signed ontology rule then restricts receiver
selection to that exact human; authorized actors may discover a route only under
human-authored policy. The singleton replacement remains one ordinary transaction.
The route is explicitly not evidence of presence.

The existing socket lifetime owns gproc registration. Renewal retains its token,
while invalidation, expiry, identity replacement and termination unregister it.
Two tabs use distinct tokens and closing one leaves the other registered. The
real socket fixture checks replacement with a different human sharing the same
signing key, and ignores a retired expiry timer. A later native preparer must
also compare the actual installed expiry, because a timer can still be queued.
No live acceptance predicate or writable live-observation bypass is introduced.

The client signs receiver selection through the ordinary operation journal.
Unknown and pending replies retain exact bytes/signature; a replacement socket
refuses another selection until that operation is resolved. A missing journal
fails closed. Renewal does not repeat selection. The temporary failed test was
an existing term-parser contract violation (period-terminated source supplied as
a term); using the existing instance-text convention fixes it, and the fixture
now also releases its wait on an error so failure cannot hang the test.

regression 2/0, all true exit0. Repeated signed receiver reads and HUD renewal
are traced for unchanged-operation I/O. This slice adds 107 net production lines
for the route/connection binding and portable adapter. It adds no process,
question inventory or presentation engine. Self-review only; no Claude review
is claimed. Native acceptance, actual opening and hardware acceptance remain
