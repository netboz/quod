# Remaining component contracts

Continue through the common class compiler, ordinary GUI view and both existing adapters. No domain engine, queue, executor or server-side draft visibility state.

Image uses the existing asset(Digest, <<"image/jpeg">>) encoding and the existing render-resource owner's verified bytes/cache. The resource owner supplies ref-counted object URLs for DOM and Babylon GUI image consumers, sharing bytes with existing scene textures. It revokes URLs on the final release and ignores retired async completion. Accessible labels remain visible; load failures are visible. Icon is an image subclass. Icon button is a button subclass with the same button projection and optional image attribute, so activation/binding stays on the existing path.

A basic table specializes selectable_list. Its options retain stable row IDs; labels become ordered binary cell lists and headings declare the matching columns. Single/multiple selection uses the existing value conversion and ontology membership checks. Both adapters render a bounded row region, column headings and selection. Columns reflow into labelled rows where horizontal width is insufficient. Projected rows are authored finite data; no new query language or mutable row store.

Menu and dialog specialize container. Their open/close visibility is local adapter state, like tabs. Accessible labelled open and cancel/close controls, keyboard Escape and focus restoration leave the controller draft intact. A local cancel closes the transient; it does not cancel the shared question or commit fields. Domain buttons still invoke only the controller's existing authorized actions. Hidden child actions must remain hidden, not escape to the permanent footer.

Validation must cover real ontology schema/binding/rollback, exact field sets and unchanged repeat cost; verified asset reuse/release/corruption; desktop and windowless spatial selection, visibility, focus and draft preservation. Final Vive acceptance remains last and cannot be established by these tests.
