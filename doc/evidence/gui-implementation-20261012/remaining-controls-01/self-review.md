# Independent review of the remaining common controls

Source review by Codex; no Claude review claimed. The implementation remains in
the existing GUI vocabulary, form compiler, typed draft helpers and two adapters.
No new process, event queue, executor, transaction lane or domain-state owner.

The table specializes selection. Its stable row IDs pass through the existing
single/multiple value checks; cells must match declared headings. The same signed
binding rejects extra display fields, unknown rows and duplicate choices, with a
preceding assertion rolled back. Image/icon are display classes; icon_button
projects to the existing button contract with an optional image. Schema and
bindings remain batched, with no I/O on unchanged repeated reads.

Image decoding reuses the existing scene asset encoding and verified resource
owner. DOM/spatial URL leases share bytes with textures, verify the digest,
retain one URL until the last consumer leaves, revoke it on retirement and
ignore late completion. GUI controls release leases, while Babylon parents own
their child controls. Browser03 exposed a violation of that ownership; the
corrected path passes schema replacement and full disposal. Failed evidence is
retained in assessment.md and the numbered gates.

Tabs, menu/dialog visibility and draft edits remain client-local. Hidden actions
stay inside their container instead of escaping into the permanent action bar.
Spatial close checks current texture ownership and ancestor visibility before
restoring focus; Escape only closes a visible transient. Desktop uses the native
dialog's synchronous focus restoration, with the opener focused before opening.
There is no delayed focus mutation or second dialog state machine. Closing a
transient preserves the draft and is distinct from cancelling a shared question.

The nonphysical instrument example now uses General/Tuning/Channels tabs, a
multiple-selection channel table, multiline notes and a toggle while retaining
its original continuation and domain value types. The lobby example keeps the
same common form/lifecycle machinery. No application defines per-widget
reaction plumbing.

Browser08 passes 67 spatial boolean checks plus all prior detailed assertions,
36 desktop checks and hardware-fixture startup with zero XR entries. No unexpected
severe console errors are accepted; only the fixture favicon404 is excluded.
