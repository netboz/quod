# Fable review 3: ontology representations and governed physics

**Verdict.** The refined model is coherent with the source and needs no new presentation system. An ontology can become an ordinary instance with two declarations in the shared predicates; its source, policy and class content already flow through existing lenses, encodings and the one code Eidolon. The parent's four corrections are confirmed by the code and are not reintroduced here. Ontology should not inherit from space. The linked-physics candidate remains the right first path, and it is smaller than the plan describes once the lobby's three scopes are named correctly: the signer's user ontology, the lobby ontology, and a newly founded physics ontology.

**Most important corrections.**

4. The parent's "putting a rule only in the lobby is insufficient" is right for a concrete reason it did not state: the signer's agent lives in the user ontology, and the lobby is a separate `<user>/lobby` ontology (`quod_lobby.pl:24-33`). So three scopes are involved, not two, and the endpoint today retains only the signer scope and the world scope (`quod_client_simulation.erl:44-51`).
5. The plan's table uses "subject" as a domain concept (`:15-25`). In code it is only a wrapper term: the lens helper `subject/3` (`quod_lens.pl:244-245`) and the editor's `subject(Target, Entity)` (`quod_prolog_eidolons.pl:18`). Use "entity" or "instance" (`quod_rendering.pl:43`, `world.md:237`).

## Proposed refinement

**Ontology as instance (Q1).** Add to the shared predicates, which already own the `ontology` token:

```prolog
isa(ontology, thing).
instance_of(ontology, ontology_ref(Ns, Anchor)) :- current_ontology_identity(Ns, Anchor).
```

Each scope is an instance of `ontology` in its own scope; a foreign ask `Ns::instance_of(ontology, R)` reaches it. No registry, no root dependency. Then `entity_eidolons(ontology_ref(Ns, Anchor), E)` yields the code Eidolon through the ordinary path, and `ontology_eidolons/1` is retired rather than kept beside it. The client drops its placeholder entity and selects the anchored reference as it does for devices.

**Smallest seam for 3D content (Q2).** Recipe work only, for reads: one lens whose rows ask the target scope for `isa/2` and `instance_of/2`, and whose marks carry anchored `depicts/3`. Today lens marks are unanchored (`quod_lens.pl:245`), which `quod:rendering` calls display-only (`quod_rendering.pl:44`) and the client treats as unselectable (`World.tsx:281`, `:223`). `lens_subject/3` names the ontology without an anchor (`quod_lens.pl:32`); rows must carry it. Menus for non-lobby entities are the one shared gap: a class-selected menu next to `entity_eidolons/2`, replacing `lobby_menu/device_menu` rather than duplicating it. Edits need no new seam; they already go through `prolog_edit_goal/5`.

**ACL exposure (Q3).** Expose three distinct things and add no store. Policy text: the `can_invoke/4` and `can_*` clauses through the existing predicate-source lens (`quod_lens.pl:291-292`), governed by the existing source-read authority. Public shapes: the existing `*_query/1` catalogues. The caller's standing: purpose-scoped, principal-relative verdict reads in the style of `system_source_access/2`, one per authority (source read, policy read, edit). Do not add a generic "may I invoke Goal" predicate: it would be the privileged oracle the brief forbids, and it cannot reproduce the future call's chain. Effective permission for an action is learnt only from the real signed request's result class (`proofs.md:49-73`).

**Space (Q4).** Concrete definition from the code: a space is an instance in some ontology that holds containment facts, placement facts giving each member a frame, and optionally a physics world assignment. The lobby is the only such instance today (`quod_lobby.pl:41-52`), and a world is a name inside an ontology, not the ontology (`quod_physics.pl:63-68`). Inheritance would require every ontology, including `quod:rendering`, to own containment, placement edits with ACLs and physics eligibility, and it would push layout into durable truth, which the world contract keeps rebuildable (`world.md:10-13`). The licence lens already proves a nonphysical, fully graphical space with no placement facts. So: ontology is an instance of `ontology`; it gets spatial representations through lenses; it may additionally own space instances. Declare `isa(lobby, space)` only when a second space class appears.

**Chair owned in A, admitted to B (Q5).** Authorization is a B action under `can_edit_physics/2` with A's consent as a certified read. Exclusive placement needs an A-side epoch write in the same atomic group, since two B-side commits reading one unchanged A fact both validate. B materializes a descriptor with `class_ref/4` provenance; a later A edit changes nothing until B re-adopts, and a forced change is one A+B group. Withdrawal is a B action, or an A+B group releasing the epoch while B retracts the body, advances structure and removes the checkpoint. Rollback uses action savepoints and group abort. Recovery uses B's fences and fresh generations; A's absence authorizes nothing new. Unknown outcomes resolve by original identity. Pushes and layout moves stay single-writer or transient. This whole slice is new work and is not needed for the lobby.

**Linked physics (Q6).** The smaller path: found B with the physics module; author its floor, roof, console and openings as explicit colliders in B; author a B-local controlled agent and viewpoint; author `physics_client_world(ontology_ref(B))` in the user ontology; grant the user's agent view and control in B's policy. Explicit mapping, no refound; the lobby and user ontologies keep identity and history. The frame honestly names B as the physical domain (`frame.world`), and the lobby's console appears with its own anchored identity once the same-identity restriction is lifted.
