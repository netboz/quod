# Operator and appearance diagnostics

The initial preflight created an empty output directory then rejected its image
assertion because it included the existing Alpine preparation task. It submitted
nothing. Preflight-02 restricts that comparison to Quod images and captured the
unchanged candidate v95/index869134, eight active nodes and 33 ontology prefixes.

Shared source prepare-01 was read-only and failed in the general Erlog reader;
this operator reader did not accept the signed goal grammar. Prepare-02 used the
signed parser but passed opaque remote functors to the trusted in-VM API, which
expects materialized terms. Prepare-03 uses that parser plus the existing bounded
materialize_symbols function for this known operator goal, and compiled the exact
source-guarded transaction. Neither failed attempt submitted a transaction.
Their stdout, stderr and true remote exits are retained. Remote eval returned
exit0 even on an Erlang eval error; the recipe therefore requires a parsed
successful result, not that exit alone.

The appearance fixture's first attempt failed before signing. Attempt02 returned
a definite `fail` from its combined texture query. The ordinary local operation
journal retained that refusal because the diagnostic omitted its terminal callback.
Attempts03/04 refused any new write while it remained pending. The exact saved
failure was consumed only for the agent-owned account and matching diagnostic
context; this was not resolution of an unknown write. Attempt05 committed using
separate catalogue queries and left zero pending operations. Only Distant Heights
was changed. The preparation/refusal/consumption/success evidence is retained.

Appearance-preview-01 used a diagnostic old-wire adapter with the current renderer,
never a release source. Its 60s readiness wait expired as the deployed sequential
216-chunk stream completed; the failure screenshot shows the textured world and
sky ready after that deadline. It did not reach its movement measurements and is
not a passed acceptance test. Earlier successful visibility-only diagnostics and
the packet timing comparison remain distinct.

Clean-presentation-04 was terminated at a documented SIGTERM after review-03
identified a stale GUI helper and mismatched lobby brightness. Its first failure
appears after the SIGTERM line and is a shutdown consequence. The child returned
exit0 but no completed EUnit summary; the runner correctly recorded STOP and did
not run later gates. Clean-presentation-05 is separately frozen to review-04 and
requires all twelve gates. No partial run is reported as passing.
