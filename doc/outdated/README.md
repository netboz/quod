# Archived documentation

This folder contains the previous architecture, implementation plans,
measurement reports, figures and PDF specifications. The files were moved
here while the [current documentation](../README.md) was rewritten.

Read these records for exact historical rulings and evidence. Their dates,
status notes and references to “current” work reflect the time they were
written. Some protocol constraints remain applicable; check the current
source and [working agreement](../../AGENTS.md) before changing semantics.
Older handoffs may still cite a former `doc/<name>` path; find that file here
as `doc/outdated/<name>`.
