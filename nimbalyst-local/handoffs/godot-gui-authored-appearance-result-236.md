## Implemented shared contract

`property(appearance, inherit)` keeps the enclosing appearance or usable offline
defaults. `appearance(1, Tokens)` admits unique renderer-neutral RGB colour,
integer spacing/padding/corner and permille panel-opacity tokens. Unknown versions,
names, duplicates and invalid values are refused. The native renderer translates
tokens into existing Theme/StyleBox resources; no CSS, executable property, new
GUI executor, field registry or domain owner was introduced.

`gui_compile/6` hashes the semantic tree with only appearance omitted. Subject,
binding, continuation, values, permission and original-operation owners remain
unchanged. Operations and deferred questions preserve their semantic revision,
native controls, dirty values, selection/caret and explicit submission. Source
and workbench consumers distinguish semantic controls from appearance. Temporary
signed refresh hides retained presentation and withdraws input/picking; terminal
denial, subject replacement and disposal retire it. Exact source dependency
version and semantic workspace checks govern stored-source reuse. Computed lenses
re-evaluate their existing signed cursor on each accepted refresh: target history
cannot validate recipe computation or live runtime data. Identical text is not
assigned again, preserving native selection/caret. No focus restoration or hidden authorization
renewal was added.

Only panel backgrounds may be translucent. Native text, controls, popups, status
and the adjacent keyboard stay opaque. Desktop opacity and local Larger text /
Opaque preferences take precedence. Geometry changes use the existing capture
cancellation path. Unchanged tokens reuse the existing theme/style resources.

The browser's existing closed parser now accepts the shared `inherit` property.
Its current Babylon/React renderers explicitly refuse non-inherit authored tokens;
they do not silently discard them. This checkpoint qualifies the Godot consumer,
not browser authored-theme rendering.
