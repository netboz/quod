- **Runs in the caller or worker, never a state owner.** HTTP resolution runs in the request process ([src/quod_client_goal_ingress.erl:248](/home/yan/src/quod/src/quod_client_goal_ingress.erl:248)); the endpoint path runs inside the `spawn_monitor` worker ([src/quod_simplex.erl:6045](/home/yan/src/quod/src/quod_simplex.erl:6045)), which calls back into the owner asynchronously. No deadlock path found.
- **Signing key, session, digest, scope, anchor, winning claim.** Unchanged and still in front of the read: `resolve_verified_operation` binds the session key, `resolved_operation` compares the claim digest (`operation_conflict`), `outcome_snapshot` rejects a wrong anchor, `result/2` pins `{Ns, Anchor}` so a foreign anchor yields `invalid_identity`, and the claim's `outcome_ref` is read before any selector. - **Deadlines, incarnation, recovery, unavailable evidence.** Both callers pass their absolute monotonic deadline through `history_view` and the read. `with_local_view_owner` re-checks the registered owner pid before and after the read. - **Current-committee corroboration includes bindings.** `count_match` keys on the whole outcome map ([src/quod_dtx_current_view.erl:1300](/home/yan/src/quod/src/quod_dtx_current_view.erl:1300)); the codec requires `bindings` with strictly ascending unique names for ordinary committed replies and rejects duplicates. The new current-view test exercises divergent vs identical bindings at f+1.
- **Lane parity and variable exclusion.** `result_bindings/2` is shared by both implemented lanes. The durable result is sealed through `quod_proof_context:durable_bindings/1` → `quod_client_goal:named_bindings/2` ([src/quod_prolog.erl:5303](/home/yan/src/quod/src/quod_prolog.erl:5303)), the same signed-name projection the live reply uses, so `_` and clause-internal variables are excluded by construction. `encode_result` sorts names, matching the codec's ordering rule. Synchronization uses `projection_advanced` and `replay_ready` subscriptions, not sleeps.
- **Removal of the superseded path.** The 3-key committed codec clause is gone; the old fixture-only ingress test was rewritten to assert uncertainty without retained history, with its winning-claim and selector obligations moved to the real-owner test. The compact APIs retained are live consumers, not alternatives.
